# 物流异常客户工单闭环

## 目标

对标马帮的物流异常处理，系统不只在运营后台记录派送失败、地址异常、签收证明和赔付状态，还要自动把需要客户确认的事项同步到客户工作台，形成“运营登记 - 客户可见 - 处理进度回传 - 工单关闭”的闭环。

## 已落地能力

- 运营在物流控制台登记派送失败、地址异常、丢件、退回、签收证明或赔付事项时，系统自动创建客户工单。
- 运营上传追踪号 CSV 时，系统可按“物流状态、异常类型、签收证明链接、赔付金额”等列自动识别异常或签收证明，并同步生成客户工单。
- 工单分类为“物流异常”，初始状态为“等待客户”，客户可在工作台待办中看到并继续沟通。
- 物流异常记录会保存关联的客户工单号，运营后台最近异常列表可直接看到对应 `WO` 编号。
- 运营更新异常状态、签收证明、改派要求或赔付状态后，系统会自动追加一条客户可见的工单消息。
- 当异常标记为“已处理”或“已忽略”时，对应客户工单同步结案。
- 客户在追踪查询页面可看到异常说明、工单号、改派要求、签收证明状态和赔付进度。
- 运营后台 SLA 面板已纳入工单响应：客户已回复、运营工单超时、客户待回复都会进入风险看板。

## 使用路径

1. 运营后台进入“物流控制台”。
2. 选择出库单，填写异常类型、说明、是否需要改派、签收证明链接、赔付金额和赔付状态。
3. 提交后系统生成物流异常记录，并自动创建客户工单。
4. 客户进入工作台待办，按工单继续补充地址、确认改派或查看运营处理说明。
5. 运营在最近异常记录中更新处理结果，客户工单同步追加进度。
6. 异常处理完成后选择“已处理”，客户工单同步关闭。

## 追踪回传 CSV 字段

模板字段包括：出库单号、追踪号、承运商、服务名称、物流状态、节点说明、地点、异常类型、是否改派、改派说明、签收证明链接、赔付金额、赔付状态、赔付备注。

- 物流状态填写“异常、派送失败、地址异常、退回仓库”等，会自动按节点说明推断异常类型。
- 异常类型可直接填写“派送失败、地址异常、收件人不在、运输破损、疑似丢件、退回仓库、物流赔付、签收证明、其他异常”。
- 物流状态为“已签收”且填写“签收证明链接”时，会生成签收证明记录并同步到客户侧。
- 填写“是否改派=是”时，会把改派说明同步到客户工单，方便客户确认新地址或派送时间。
- 填写赔付金额、赔付状态、赔付备注时，会写入物流异常赔付进度，并进入 SLA/异常报表。

## SLA 口径

- 客户已回复的工单优先进入运营处理队列。
- 运营待处理超过 24 小时未推进，视为工单超时。
- 运营处理中超过 48 小时未更新，视为工单超时。
- 等待客户补充的工单计入“客户待回复”，方便运营跟进提醒。
- “导出 SLA 报表”会同步导出工单超时、客户已回复和待客户补充记录，字段保持中文。

## 后续可增强

- 将承运商 API 的真实轨迹异常自动写入同一条闭环。
- 支持签收证明 PDF 文件直接下载，而不只是保存链接。
- 将赔付到账动作联动到账单抵扣或客户余额。
- 增加物流异常 SLA 和客户未回复提醒。
