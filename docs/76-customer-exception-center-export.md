# 76. 客户侧我的异常中心导出

## 本轮目标

让客户不只下载物流异常，而是能下载自己的综合异常中心明细，覆盖入库、出库、物流、退货、库存和费用风险。

## 已完成

- `/api/downloads?kind=exceptions` 新增客户侧异常中心 CSV。
- 客户门户“可下载内容”增加“我的异常中心”。
- 门户里带“物流 / 异常 / 赔付”的下载入口改为综合异常中心。
- 原 `/api/downloads?kind=delivery-exceptions` 保留，兼容旧链接。

## 导出范围

- 入库收货差异和入库状态异常。
- 出库作业异常和物流派送异常。
- 退货/RMA异常与客户待确认。
- 低库存、冻结库存、残次品和高库龄风险。
- 账单逾期风险。

## 导出字段

模块、异常编号、关联单号/SKU、异常类型、状态、严重程度、异常说明、下一步动作、创建时间、关闭时间。

## 价值

客户可以直接看到“自己还有哪些异常要处理或等待处理”，这比只提供物流异常更接近马帮类系统的客户自助体验。
