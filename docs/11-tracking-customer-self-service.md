# 查进度与客户自助入口交付记录

## 产品经理判断

调研团队把需求交给产品经理后，优先级最高的新增网站能力是“查进度 / 待我处理”。原因很简单：中国跨境卖家提交询盘或入库预报后，最怕信息掉进黑箱，只能在微信里反复问客服。

这一轮先做轻量自助查询，让客户能用询盘编号、ASN 编号、手机号、微信号或追踪号查到当前状态和下一步。

## 已完成

- 新增 `/tracking` 页面。
- 新增 `/api/tracking` 接口。
- 头部增加“查进度”入口。

- 入库预报表单升级为 3 步向导：基础信息、货物信息、资料确认。
- 查询结果展示：

  - 编号
  - 客户/店铺名称

  - 当前状态
  - 下一步动作
- 桌面端和 390px 移动端均无横向滚动。

## 查询规则

原型阶段从本地 `.local-data/submissions.json` 查询，匹配字段包括：

- 询盘编号
- ASN 编号
- 公司/店铺名称
- 联系人
- 手机/微信
- 平台
- 承运商/追踪号
- 主要品名 / SKU

正式版需要增加权限校验，不能让任何人凭手机号或编号看到敏感业务信息。

## 后续正式版需求

1. 短信/邮箱/微信验证码。
2. 客户登录后查看自己的货件。
3. 待补资料清单：箱唛、装箱单、SKU 清单、EORI 授权、标签文件。
4. 异常确认：数量差异、破损照片、无标签、未预约、地址异常。
5. 质检照片：退货、破损、换标前后照片。
6. 账单明细：费用来源、计费规则、待确认/已确认状态。
7. 客服协同：客户提交补充资料后自动进入客服/仓库后台队列。
