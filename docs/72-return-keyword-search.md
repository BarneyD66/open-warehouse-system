# 退货/RMA 关键词搜索

## 目标

退货处理常见查询入口是 RMA 单号、买家退货追踪号、原平台订单号、客户编号或 SKU。系统需要让客户和运营快速定位退货单。

## 已落地能力

- 客户退货页支持关键词搜索。
- 客户可搜索 RMA、买家退货追踪号、原订单号、SKU、平台和退货原因。
- 客户搜索可与状态筛选组合使用。
- 运营后台退货 / RMA 表支持关键词搜索。
- 运营可搜索 RMA、客户编号、平台、原订单号、追踪号、SKU 和退货原因。
- 运营搜索可与状态汇总筛选组合使用。

## 后续可增强

- 增加日期范围筛选。
- 增加客户、平台、处理方式的下拉筛选。
- 支持保存常用筛选视图。
