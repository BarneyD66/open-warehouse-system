# 利润与成本报表

本次补齐对标马帮常见经营报表中的“利润/成本”导出能力。

## 已完成

- 新增 `/api/ops/reports/profit`。
- 按客户和月份汇总：
  - 账单数
  - 账单收入
  - 已收款
  - 待收款
  - 争议金额
  - 预估承运商成本
  - 实际承运商成本
  - 毛利
  - 毛利率
  - 出库单数
  - 已发货单数
- 支持筛选 `month` 和 `customerCode`。
- 导出动作写入审计日志。
- 保存视图中的“利润/成本”模块现在会导向该独立报表。
- 运营后台报表下载区新增“导出利润/成本”入口。

## 后续扩展

当前成本口径优先使用出库单的实际承运商费用，缺失时使用预估承运商费用。后续接入真实承运商账单后，可直接以承运商账单为实际成本来源。
