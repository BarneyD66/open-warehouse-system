# FIFO 批次拣货建议

## 目标

对标马帮/WMS 的批次、效期和先进先出能力，出库作业不能只显示 SKU 总数量，还要告诉仓库人员优先从哪个批次、哪个库位拣货，并提示批次库存不足。

## 已落地能力

- 库存批次台账已支持批次号、效期、库位、序列号、可用数量、预留数量、冻结、释放、消耗。
- 新增统一的出库批次推荐规则：按客户、SKU 匹配可用批次，排除冻结、过期、用完和无可用库存批次。
- 推荐顺序采用效期优先，效期相同时按批次创建时间先进先出。
- 仓库出库作业表的 SKU 明细下方会显示建议批次、数量、库位和效期。
- 单票拣货单和批量拣货单打印页会同步显示建议批次。
- 如果可用批次数量不足，会显示缺口数量，提醒仓库或运营先处理库存异常。

## 使用方式

1. 运营或仓库先在“批次 / 效期 / 序列号台账”登记真实批次。
2. 出库单进入拣货后，仓库页面会在 SKU 明细下展示建议批次。
3. 仓库打印单票或批量拣货单，按建议批次和库位拣货。
4. 若出现“暂无可用批次”或“缺口”，先核对是否批次未登记、库存被冻结、效期已过或库存不足。

## 后续可增强

- 扫码拣货时强校验批次号，防止扫错批次。
- 出库签出时按推荐批次自动扣减批次数量。
- 支持客户指定批次、禁用临期批次和按平台规则锁定批次。
- 批次扣减结果同步到客户库存流水和出库明细导出。
