# 出库批量拣货波次

## 本次补强

- 出库批量处理面板新增“生成拣货波次”。
- 支持按作业模式、承运商、物流渠道或合并为一个波次来分组。
- 批量生成后会写入：
  - 作业模式
  - 波次号
  - 拣货单号
  - 篮号/格口
  - 指派拣货员
  - 出库操作日志
- 已发货和异常阻塞的出库单会被跳过，避免误生成新作业。
- 每次批量生成波次都会写入 `outbound_pick_wave_batch` 审计日志。

## 对标价值

马帮类 WMS 的出库作业不会只靠逐单处理。批量波次可以把订单按渠道、承运商、SKU 结构或作业模式组织起来，仓库可以批量打印拣货单、扫码拣货、分拣复核，运营也能追溯是谁生成了哪一批波次。
