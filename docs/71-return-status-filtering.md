# 退货/RMA 状态筛选

## 目标

退货列表随着业务增长会越来越长，客户和运营都需要快速切到某一类待处理退货，而不是一直滚动查找。

## 已落地能力

- 客户退货页汇总卡片支持点击筛选。
- 客户可按已提交、运输中、质检中、待确认和已完成查看退货。
- 客户筛选使用 URL 参数，刷新页面后状态仍保留。
- 运营后台退货 / RMA 汇总条支持点击筛选。
- 运营可按未补追踪、待到仓、质检中、客户待确认、客户已确认和待结束查看退货。
- 当前筛选没有数据时，会显示明确空状态。
