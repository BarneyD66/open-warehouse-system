# 客户确认退货处理方式

## 目标

退货质检后，处理方式不能只靠微信或口头确认。系统需要让客户在工作台里结构化确认“重新上架、维修翻新、报废销毁、转寄”，并把确认结果同步给运营、工单和导出报表。

## 已落地能力

- 客户退货页面新增“确认退货处理方式”面板。
- 客户可选择重新上架、维修翻新、报废销毁或转寄。
- 客户可填写确认备注，例如转寄地址、维修要求或报废说明。
- 提交后退货单会记录客户确认方式、确认备注和确认时间。
- 如退货单已有售后工单，系统会自动追加客户确认消息，并把工单状态推进为处理中。
- 运营后台退货列表可直接看到客户确认结果。
- 客户下载退货质检明细 CSV 时，会包含客户确认方式、确认备注和确认时间。

## 使用路径

1. 客户提交退货预报。
2. 仓库扫码到仓并进入质检。
3. 运营填写质检结果或上传质检附件。
4. 客户在退货页面查看质检结果后选择处理方式。
5. 运营根据客户确认继续重新上架、维修、报废或转寄。

## 后续可增强

- 对“报废销毁”和“高价值维修”增加二次确认。
- 转寄时增加结构化地址表单和运费预估。
- 客户确认后自动生成待办提醒给运营负责人。
