# 75. 运营异常中心报表

## 本轮目标

对标马帮的异常中心，把分散在入库、出库、物流、退货、库存和费用里的异常汇总成一张运营可导出的中文表。

## 已完成

- 新增 `/api/ops/reports/exceptions`。
- 覆盖入库收货差异、入库状态异常、出库扫码/作业异常、物流派送异常、退货/RMA待确认或异常、库存风险、账单逾期和运费差异。
- 支持筛选参数：
  - `module`：模块，例如 `入库`、`物流`、`库存`、`退货/RMA`。
  - `status`：状态，例如 `待处理`、`处理中`。
  - `severity`：严重程度，`提醒` 或 `严重`。
  - `customerCode`：客户编号。
  - `keyword`：关键词。
- 保存视图支持 `exceptions` 模块。
- 报表中心增加“导出严重异常”快捷入口。
- SLA 与异常看板增加“导出异常中心”按钮。

## 导出字段

模块、异常编号、关联单号/SKU、客户编号、异常类型、状态、严重程度、异常说明、负责人、下一步动作、创建时间、关闭时间。

## 价值

运营和老板可以从同一张表里看到所有未处理风险，而不是分别打开入库、出库、物流、退货、库存和账单页面逐个查。后续如果做独立异常中心页面，这个接口可以直接作为数据基础。
