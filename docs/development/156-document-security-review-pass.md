# 156 - 文件安全复核与放行闭环

## 背景

系统已有文件上传、基础安全扫描、对象存储网关、预览、签名下载和文件安全台账，但运营后台缺少对待扫描/异常文件的人工处理能力。生产使用时，文件资料不能只记录状态，还需要能复扫、放行、拦截并留下审计。

## 本次开发

- 新增文件安全状态更新能力，支持把文件标记为待扫描、已通过或已拦截。
- 新增文件复扫能力，使用现有基础扫描和外部病毒扫描配置重新检查文件。
- 新增运营 API `/api/ops/documents/[id]/security`，支持 `rescan`、`mark_clean`、`block`、`mark_pending`。
- 新增 `DocumentSecurityActions`，运营可在资料审核表直接复扫、放行、拦截文件。
- 文件预览、下载、客户资料归档、资料上传面板、客户下载清单统一改为“只有已通过安全扫描才开放预览/下载”。
- 所有安全处理动作写入审计日志，记录操作人、客户、文件、状态、说明和业务关联单号。

## 验收口径

- 待扫描文件不会出现在客户可下载/可预览入口中。
- 已拦截文件不可下载、不可预览。
- 运营可以在后台资料审核区复扫、人工放行或拦截文件。
- 文件安全处理后报表中心、文件安全台账、客户资料归档会按最新状态展示。
