# Pass 180 - API 联调事件台账

## 背景

对标马帮后，系统已经具备承运商面单、轨迹/POD、平台拉单、取消复核和发货回传的基础能力，但真实生产使用时还需要一个统一台账，让运营能看清每次外部接口、Webhook 和自动任务是否闭环。

## 本轮完成

- 新增运营后台组件 `OpsApiIntegrationLedgerPanel`。
  - 汇总承运商/平台 Webhook、接口探测、面单重试、轨迹同步、平台拉单、取消复核、发货回传、自动任务审计。
  - 展示接口事件总数、闭环完成、失败/异常、处理中、承运商回调、平台回调。
  - 自动列出优先处理事项，并给出下一步动作。
  - 展示承运商下单/取消、承运商轨迹/POD、平台拉单/取消、平台发货回传四类闭环能力状态。

- 新增报表接口 `/api/ops/reports/api-integration-events`。
  - 支持 CSV 导出和 `format=json`。
  - 支持按来源、状态、供应商/平台、客户编号、关键词筛选。
  - 导出字段使用中文，包含来源、分类、供应商/平台、事件编号、状态、关联单号、摘要、错误信息、发生时间、更新时间、下一步处理。
  - 增加权限校验、限流和导出审计。

- 接入运营后台总览。
  - 放在 Webhook 回调台账之后，便于从总览直接看到真实 API 闭环质量。

## 验证

- `npm run lint`
- `npm run build`

两项均通过。
