# 213 员工登录失败锁定与安全告警

## 本轮目标

继续补齐生产级员工账号和权限能力，让正式员工账号具备上线必需的登录安全保护。

## 已完成

- 正式员工账号新增登录失败安全字段：
  - 连续失败次数；
  - 最近失败时间；
  - 最近失败原因；
  - 临时锁定到期时间。
- 正式员工账号连续 5 次密码错误后自动锁定 30 分钟。
- 成功登录后自动清空失败次数、失败原因和锁定状态。
- 运营后台员工账号治理卡片展示失败次数、锁定到期时间和最近失败原因。
- 员工账号维护 API 新增 `unlock` 动作，管理员可解除登录锁定。
- 解锁动作保留敏感操作二次确认和审计日志。
- 系统告警中心新增“员工账号登录锁定”告警，跳转到权限模块处理。

## 产品价值

- 正式员工账号不再只是白名单登录，具备基础防爆破能力。
- 管理员可以在后台看到异常登录风险并解除锁定。
- 老板和运营总控台可以看到被锁定员工账号，避免仓库/运营账号被锁后没人发现。

## 下一步建议

- 登录失败和锁定事件单独写入审计日志搜索。
- 后续可增加管理员重置密码通知、员工设备/IP 风险提示和 MFA。
