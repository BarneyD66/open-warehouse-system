# Pass 183 - 客户物流证据包

## 背景

客户侧已有面单、签收证明和物流异常导出，但证据分散。日常使用时，客户更需要一份能直接对账、追踪、留档和沟通售后的完整物流证据包。

## 本轮完成

- 新增客户下载类型 `logistics-evidence`。
  - 下载地址：`/api/downloads?kind=logistics-evidence`
  - 文件名：`物流证据包-{客户编号}.csv`
  - 字段包含：出库单号、平台订单号、物流渠道、承运商、服务、追踪号、面单状态、面单链接、签收状态、签收证明链接、最新轨迹、异常数量、异常摘要、赔付金额、赔付状态、客户确认、预估运费、实际运费、运费差异、费用差异说明、下一步处理。

- 更新客户工作台下载中心。
  - 新增“物流证据包”卡片。
  - 计数逻辑覆盖已生成面单、追踪号、轨迹、异常和实际运费记录。

- 更新自助下载索引。
  - `self-service-index` 会包含“物流证据包”并显示当前可用数据数量。

## 验证

- `npm run lint`
- `npm run build`

两项均通过。
