# 133. 客户自助付款核销记录下载

## 本轮范围

- 客户工作台下载中心新增“付款核销记录”。
- `/api/downloads?kind=payment-reconciliation` 新增客户侧 CSV 导出。
- 导出内容仅包含当前登录客户的数据，字段包括账单编号、月结单号、账单金额、账单状态、核销状态、付款参考号、提交付款时间、核销时间、复核人、驳回原因、争议说明和下一步处理。
- 客户账单页新增“导出付款核销记录”入口。
- 自助下载资料索引同步纳入付款核销记录数量。

## 生产化价值

- 客户可以自助核对自己提交的付款参考号、到账核销状态、被驳回原因和争议处理状态。
- 与运营侧“收款核销台账”形成内外一致的对账闭环。
- 降低客户反复向客服询问“付款是否核销”的沟通成本。
