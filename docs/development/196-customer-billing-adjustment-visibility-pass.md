# Pass 196 - 客户侧账单调账/赔付可见性

## 本轮目标

把财务复核后产生的费用调账和赔付抵扣结果同步展示到客户账单页和客户通知里，避免客户只看到原账单争议状态，看不到处理结论。

## 已完成

- 客户账单页新增调账/赔付统计卡。
- 调账/赔付账单增加专属标签：费用调账、赔付抵扣。
- 调账/赔付账单展示来源工单和原账单编号。
- 原账单下方会展示已关联的复核调整记录。
- 客户通知中心识别调账/赔付账单，不再按普通待付款账单提醒。
- 调账/赔付客户通知显示来源工单、原账单和“已同步到账单中心”的说明。

## 业务价值

客户可以直接看到争议处理结果，明确知道系统已经生成调账或赔付抵扣，不需要再依赖客服单独解释。员工后台、报表中心和客户侧账单页的口径也保持一致。

## 下一步

- 继续补客户侧“账单争议处理进度”时间线。
- 将调账/赔付结果纳入月结单页汇总说明。
