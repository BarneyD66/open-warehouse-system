# 189 财务复核工单回写账单

## 本轮目标

让客户提交的费用复核/账单争议工单不只停留在工单层，而是在财务完成复核时尽量同步回写到具体账单。

## 已完成

- `BillingRecord` 新增可选 `workOrderId` 字段，用于承载账单和客户工单的关联关系。
- 员工账单复核方法支持在回写账单时保存来源工单号。
- 财务复核工单 API 会按显式账单号、工单关联单号、描述中的账单号自动匹配账单。
- 财务点击“完成”时，如果匹配到账单，会自动执行账单 `resolve_dispute`，写入复核备注并保留审计日志。
- 财务面板会展示“已匹配账单”或“未自动匹配账单”的提示，避免员工误以为账单已同步处理。
- 完成复核会继续关闭工单，账单回写失败不会影响无法匹配账单的工单闭环。

## 对标马帮价值

- 客户费用异议从“工单沟通”推进到“账单状态同步”，更接近日常财务处理闭环。
- 财务可以在同一面板看到客户说明、内部提示、证据包、关联账单和处理动作。
- 审计日志保留从工单到账单的处理依据，后续可用于争议追溯和绩效统计。

## 下一步建议

- 增加结构化复核结论：同意调整、维持原账单、赔付处理。
- 支持复核成立时自动生成负数调整账单或补差账单。
- 将账单回写结果展示到客户侧工单详情里。
