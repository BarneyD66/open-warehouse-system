# 客户资料中心与中文导出清理

## 本次目标

对标马帮客户侧自助能力，补强客户可直接查看和下载的资料入口，并清理文件上传、预览、下载和 CSV 导出的中文文案。

## 已完成

- 客户资料上传 API、运营资料上传 API、文件下载 API、文件预览 API 的错误提示恢复为中文。
- 资料上传面板恢复中文按钮、提示、空状态、预览和下载文案。
- 文档仓库分类、业务类型、安全扫描状态和存储状态标签恢复为中文。
- 客户下载接口 `/api/downloads` 重写为中文导出，覆盖库存、库龄、库存流水、进销存、批次效期、出库、出库复核、费用、付款核销、面单、签收证明、物流异常、异常中心、退货和自助索引。
- 客户工作台新增“我的业务资料”归档面板，展示最近资料、业务类型、关联单号、上传来源、安全拦截数、预览和签名下载入口。
- 自助下载中心新增“资料归档清单”，可导出文件编号、文件名、业务类型、关联单号、分类、安全状态、预览链接和签名下载链接。

## 价值

客户不再只能在分散业务页上传资料，可以在工作台首页集中查看资料沉淀；下载的 CSV 文件名、表头和状态说明也保持中文，适合直接给客户使用。

## 验证

- 待随本轮整体执行 `npm run lint` 和 `npm run build`。
