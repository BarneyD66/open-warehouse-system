# 216 文件上传拒绝审计与告警

## 本轮目标

继续补齐对象存储与文件安全能力，让被安全策略拒绝的上传也进入可追溯、可告警的生产台账。

## 已完成

- 审计日志新增 `document_upload_rejected` 动作。
- 客户上传资料被安全扫描、文件类型或存储流程拒绝时，写入审计流水。
- 员工后台上传客户资料被拒绝时，写入审计流水。
- 拒绝审计不保存文件内容，只记录：
  - 客户编号；
  - 关联业务类型和单号；
  - 文件名；
  - MIME；
  - 文件大小；
  - 拒绝原因。
- 操作审计页面和审计导出接口补充“文件上传被拒绝”中文标签。
- 系统告警识别文件上传拒绝事件，并归入资料文件风险。

## 产品价值

- 危险文件、异常附件和外部病毒扫描阻断不再只是一个前端报错。
- 老板和运营可以在审计日志、系统告警里看到谁上传了什么、为什么被拒绝、关联哪个业务单。
- 文件安全从“入库后复核”补齐为“上传前拦截也可追踪”。

## 下一步建议

- 对同一客户、同一 IP 或同一文件名连续拒绝增加聚合风控。
- 文件安全看板可增加“最近拒绝上传”列表，减少运营翻审计日志的成本。
