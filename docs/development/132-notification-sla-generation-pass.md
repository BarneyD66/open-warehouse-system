# 132. 通知与 SLA 提醒主动生成

## 本轮范围

- 新增 `/api/ops/notifications/generate-due`。
- 支持员工或系统密钥触发，系统密钥读取 `NOTIFICATION_GENERATE_SECRET`，没有则回退 `CRON_SECRET`。
- 扫描员工待办、客户待办、SLA 风险、账单/物流/出库/工单提醒，并主动生成外部投递记录。
- 生产自动化 `/api/ops/automation/run-due` 增加“通知与 SLA 提醒生成”子任务。
- 自动化子任务重试 `/api/ops/automation/task-actions` 支持单独重试通知生成任务。
- 审计日志类型和运营审计面板补充“到期通知生成”。
- 运营后台“消息订阅与 SLA 提醒”增加“立即生成提醒”按钮，可手动生成员工/客户待办和外部投递记录。

## 生产化价值

- 外部通知投递不再依赖用户打开通知中心页面。
- 自动化调度会先生成提醒，再执行已有的通知投递重试任务。
- 邮件、短信、微信等渠道仍复用已有投递状态、失败重试和审计链路。

## 验证

- `npm run lint`：通过。
- `npm run build`：通过，新增路由 `/api/ops/notifications/generate-due` 已出现在构建路由表。
- 冲突标记检查：通过。
