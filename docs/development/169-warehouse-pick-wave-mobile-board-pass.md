# 169 仓库端出库波次进度看板

## 本轮目标

继续补齐对标马帮后的“出库波次与拣货效率”能力，把已有的批量组波次、扫码进度和波次报表，进一步前移到仓库现场工作台，让员工和老板在移动端也能直接看懂每个波次卡在哪一步。

## 已完成

- 新增共享计算模块 `src/lib/pickWaveProgress.ts`：
  - 按波次聚合出库单。
  - 计算应拣数量、已拣、已分拣、已复核、待称重、异常数、严重异常数。
  - 自动判断波次状态：有异常、疑似卡住、待称重、复核中、分拣中、拣货中、待交接、待开始、已完成。
  - 输出下一步处理建议，便于现场直接执行。
- 新增仓库端 API：
  - `GET /api/warehouse/outbounds/pick-waves`
  - 支持 `status`、`keyword`、`limit` 查询。
  - 返回波次数、执行中波次、风险波次、待称重订单数和明细行。
- 新增仓库工作台页面看板：
  - `WarehousePickWaveBoard`
  - 在 `/warehouse` 出库大表前展示。
  - 移动端以波次卡片展示拣货/分拣/复核进度条。
  - 展示订单数、SKU 数、待称重数、最新扫码时间、停滞小时、下一步处理。
  - 支持一键打印本波次拣货单。

## 产品效果

- 仓库员工手机端不用在大表格里找波次，能直接看到当前波次该拣货、分拣、复核、称重还是处理异常。
- 老板和运营可以快速看到波次数、异常/卡点波次和待称重压力。
- 后续如果做独立移动端扫码页，可以直接复用 `/api/warehouse/outbounds/pick-waves`。
