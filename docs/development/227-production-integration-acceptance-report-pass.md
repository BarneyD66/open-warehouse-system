# 227 生产集成验收记录

## 本轮目标

- 把生产集成从「配置是否齐」升级为「每个集成项是否完成联调验收」。
- 覆盖承运商 API、平台订单 API、对象存储、消息通知、报表投递和安全扫描。

## 已完成

- 新增 `integrationAcceptanceReport` 逻辑模块。
- 新增 `/api/ops/reports/integration-acceptance` 报表接口。
- 支持中文 CSV 和 JSON：
  - 默认导出 `生产集成验收记录.csv`
  - `?format=json` 返回结构化验收数据。
- 验收状态分为：
  - 验收通过
  - 等待探测
  - 配置待补
  - 联调失败
- 报表字段包含：
  - 分组
  - 集成项
  - 模式
  - 配置状态
  - 验收状态
  - 最近探测
  - 探测时间
  - 探测人
  - 说明
  - 缺少配置
  - 下一步动作
- 新增系统默认保存视图 `SYS-VIEW-INTEGRATION-ACCEPTANCE`。
- 报表中心新增「生产集成验收」模块和常用视图入口。
- 定时报表支持发送生产集成验收记录。
- 报表中心风险统计会把联调失败、配置待补计入风险。

## 验证

- `npm run lint`：通过。
- `npm run build`：通过。
- Next 构建路由表包含 `/api/ops/reports/integration-acceptance`。

## 下一步

- 继续把验收记录和上线复核包联动，在上线守门板中展示未验收集成项。
- 后续接入真实承运商和平台凭证后，可用这张表做上线验收证据。
