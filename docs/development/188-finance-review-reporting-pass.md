# 188 财务复核工单报表化

## 本轮目标

把客户提交的费用复核/账单争议工单纳入运营报表，避免只能在页面中临时查看。

## 已完成

- 客户自助待办报表新增客户维度 `financeReviewWorkOrders`。
- 报表汇总新增财务复核工单总数。
- 客户自助待办 CSV 汇总新增“财务复核工单”中文列。
- 运营端客户自助待办监控新增“财务复核”指标卡。
- 优先处理客户列表会把存在财务复核工单的客户纳入展示，并显示财务复核数量。

## 对标马帮价值

- 费用争议、运费差异不再只是单点处理事项，而能进入运营管理报表。
- 财务和运营可以按客户维度识别费用复核积压。
- 后续可继续对接定时报表、SLA 提醒和员工绩效。

## 下一步建议

- 将财务复核工单计入 SLA 报表的独立分类。
- 在报表中心增加按财务复核数量排序或筛选的保存视图。
- 复核完成后同步更新账单争议关闭率和处理时长。
