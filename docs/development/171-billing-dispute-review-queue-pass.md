# Pass 171 - 账单争议复核队列

## 背景

对标马帮类系统的财务实账能力，现有系统已经支持客户提交账单争议、运营单条复核、月结锁账和账单导出，但运营后台缺少一个集中处理费用异议的工作队列。财务人员需要能快速看到争议金额、逾期情况、客户说明和复核动作。

## 本次新增

- 新增 `OpsBillingDisputePanel` 客户端组件。
- 在运营后台账单模块中插入“账单争议复核队列”。
- 支持争议账单集中展示：
  - 争议账单数量。
  - 争议金额汇总。
  - 已逾期争议数量。
  - 最早待处理账单。
  - 客户说明、上次复核说明、账单来源和到期信息。
- 支持两类集中处理动作：
  - 解除异议：调用现有 `resolve_dispute` 复核动作。
  - 退回确认：将账单状态退回 `pending_confirmation`，由客户重新确认。
- 保持现有审计链路，继续通过 `/api/ops/billing/[id]` 写入复核记录和操作日志。
