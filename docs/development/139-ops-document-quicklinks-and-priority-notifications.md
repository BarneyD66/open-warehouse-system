# 139 运营资料快捷查看与带资料询盘优先待办

## 本轮目标

资料已经能归档到资料中心后，运营侧还需要做到“日常处理时直接看得到、点得开、排得上优先级”，避免员工在询盘和入库卡片与资料中心之间来回搜索。

## 已完成

- 运营询盘卡片新增资料快捷列表：
  - 显示最近 3 个资料文件。
  - 显示文件分类和安全扫描状态。
  - 支持直接预览和下载。
  - 超过 3 个资料时提示去资料中心继续查看。
- 运营入库预报卡片新增资料快捷列表：
  - 按 `refType=inbound` 和 ASN 编号匹配资料。
  - 支持直接预览和下载。
- 员工待办中心优化：
  - 新询盘会统计 `refType=inquiry` 资料数量。
  - 带资料询盘升级为“带资料询盘待优先报价”。
  - 带资料询盘严重级别提升为 critical，方便运营优先处理。
  - 待办点击跳转到对应运营分区。
- 修正不同待办的运营后台分区链接：
  - 询盘、入库、物流、账单、出库、退货、库存、审批资料分别跳转到对应模块。

## 产品价值

这一步把资料链路从“能上传、能归档”推进到“运营工作台可直接使用”。员工看到带资料询盘可以优先报价；处理入库预报时可以在卡片内直接打开装箱单、SKU 表、箱标等资料，减少搜索和沟通成本。

## 验证

- 已执行 `npm run lint` 通过。
- 后续随本轮执行 `npm run build`。
