# Pass 195 - 财务复核与调账赔付通知 SLA

## 本轮目标

把财务复核、费用调账和赔付抵扣接入现有消息中心与自动化巡检，让高风险费用争议可以主动提醒运营、财务和管理员。

## 已完成

- 员工通知中心新增财务调账/赔付账单提醒。
- 调账/赔付提醒会读取审批规则，按 SLA 小时数判断正常、即将超时、已超时。
- 金额较大或已超时的调账/赔付会升级为关键提醒，并默认进入站内信和邮件投递。
- 财务复核工单现在不再只依赖普通工单提醒，会以审批类待办进入消息中心。
- 财务复核工单达到 18 小时标记即将超时，24 小时标记超时。
- 通知生成接口增加财务复核/调账赔付统计和超时统计。
- 生产自动化巡检摘要增加财务复核/调账赔付指标。

## 业务价值

费用争议、调账和赔付不再只是报表里可查，而是能主动暴露到日常待办中。运营可以看到处理优先级，老板可以通过自动化摘要判断是否存在财务风险积压。

## 下一步

- 在运营后台财务页增加财务复核 SLA 小看板。
- 将客户侧账单争议状态和已生成调账/赔付结果展示得更明确。
