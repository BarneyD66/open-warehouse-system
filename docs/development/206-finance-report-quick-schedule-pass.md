# 206 财务审批报表一键定时发送

## 本轮目标

在默认保存视图基础上，继续补齐报表中心产品化体验，让财务人员可以直接把常用视图创建为每日发送任务。

## 已完成

- 新增 `ReportScheduleQuickCreate` 客户端组件。
- 支持输入多个收件人邮箱，按逗号、分号或换行分隔。
- 支持为四个财务审批默认视图一键创建每日发送：
  - 待审批调账/赔付。
  - 附件待补。
  - 争议待复核。
  - 付款待核销。
- 如果填写了收件人，定时报表创建后直接启用。
- 如果未填写收件人，定时报表先保存为暂停状态，便于后续补收件人后启用。
- 报表中心财务审批常用视图区块已接入该组件。

## 价值

财务人员不需要进入复杂配置流程，也能把马帮类系统常见的“每日待处理清单”快速固化成自动发送任务。

## 后续建议

- 对出库异常、承运商面单失败、平台同步失败、库存低于预警也提供类似一键定时视图。
- 给定时报表列表增加启用/暂停/修改收件人的前端操作。
