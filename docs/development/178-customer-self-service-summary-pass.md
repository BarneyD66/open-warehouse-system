# 178 客户资料包总览

## 本轮目标

在客户工作台把已有的自助下载、面单、签收证明、费用明细、资料归档、异常售后能力再聚合一层，让客户登录后更清楚哪些资料可以直接下载，哪些事项需要先处理。

## 已完成

- 新增 `CustomerSelfServiceSummaryPanel`。
- 在客户首页“我的操作清单”下方接入“客户资料包总览”。
- 汇总报表入口数量、关联数据数量和模板数量。
- 提供资料索引、自助操作清单、面单列表、签收证明四个高频下载入口。
- 展示资料归档、费用与付款、异常与售后的关键数量和下载入口。
- 当客户存在紧急待办或开放异常时，使用更醒目的提示状态。

## 业务价值

- 客户不需要在页面里找报表，登录后即可知道资料索引、面单、POD、费用和异常在哪里下载。
- 运营可以减少“资料在哪下载”的重复客服沟通。
- 对标马帮客户侧自助能力，进一步补齐客户自助下载和异常确认体验。
