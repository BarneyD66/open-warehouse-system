# 193 财务调账和赔付审批校验

## 本轮目标

把财务复核生成负数调账/赔付账单前的内控补齐，避免大额或敏感财务动作被直接执行。

## 已完成

- 财务复核生成调账/赔付前会匹配审批规则：
  - 费用调账使用 `manual_fee_adjustment`
  - 赔付抵扣使用 `claim_approval`
- 命中审批规则时会校验审批角色。
- 审批规则要求原因时，必须填写复核说明。
- 审批规则要求附件时，会优先检查资料中心是否已有 `approval` 附件；没有附件时必须显式确认“审批附件已上传或已归档”。
- 调账/赔付属于敏感财务动作，会校验当前员工是否有账单敏感操作权限。
- 如果角色配置要求二次确认，员工必须输入当前工单号才能生成调账/赔付账单。
- 财务面板新增二次确认输入和审批附件确认勾选。

## 对标马帮价值

- 费用争议处理进入可审计、可控的财务内控流程。
- 大额调账和赔付抵扣不再只是前端按钮动作，而会经过角色、原因、附件和二次确认校验。
- 后续可以继续把该机制升级为真正多级审批流。
