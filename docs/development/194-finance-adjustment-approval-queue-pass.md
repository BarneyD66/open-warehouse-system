# Pass 194 - 财务调账/赔付审批队列

## 本轮目标

对标马帮类系统在费用争议、调账、赔付和审批留痕上的管理习惯，把上一轮已经能生成的调账/赔付账单补成可检索、可导出、可保存视图、可定时发送的运营报表。

## 已完成

- 新增运营报表接口：`/api/ops/reports/finance-adjustments`。
- 报表同时聚合两类数据：
  - 待财务复核的客户工单。
  - 已由复核动作生成的费用调账/赔付抵扣账单。
- 支持按客户、类型、风险等级、状态和关键词筛选。
- CSV 表头和内容保持中文，字段包含来源工单、来源账单、审批提示、待补要求和下一步处理。
- 报表中心新增“财务调账/赔付审批”模块，并纳入风险判断。
- 保存视图、定时报表发送、运营后台快捷导出均已支持该模块。

## 业务价值

财务争议不再只是账单状态的一行记录，而是形成从客户反馈、财务复核、审批校验、负向账单、利润影响到报表追踪的闭环。老板和运营可以直接看到哪些争议还没处理，哪些已经形成调账或赔付，后续审计也能追到来源。

## 下一步

- 继续强化财务侧实账：付款核销后的调账抵扣展示、客户账期额度影响、账单争议审批流看板。
- 将高风险调账/赔付接入消息中心和 SLA 升级提醒。
