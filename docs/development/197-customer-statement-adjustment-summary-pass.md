# Pass 197 - 客户月结单调账/赔付汇总

## 本轮目标

让客户在月结单页面和账单 CSV 中都能看到财务复核后的费用调账和赔付抵扣，保持账单列表、月结单和导出口径一致。

## 已完成

- 客户月结单顶部新增“调账/赔付”汇总金额。
- 月结单新增“本月调账/赔付”说明区，展示调整单、金额、来源工单、原账单和备注。
- 月结明细表中标记费用调账/赔付抵扣，并展示来源工单和原账单。
- 客户账单 CSV 导出新增“调账/赔付类型、来源工单、来源账单”三列。

## 业务价值

客户月结对账时可以直接核对争议处理结果，不需要在账单列表、工单沟通和客服说明之间来回切换。财务导出的 CSV 也能保留调整来源，方便客户内部财务留档。

## 下一步

- 继续补账单争议处理进度时间线。
- 将财务调账/赔付审批队列进一步接入运营财务看板。
