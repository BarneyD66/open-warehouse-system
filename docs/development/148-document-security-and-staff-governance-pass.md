# 148 文件安全与员工权限生产化

## 本轮目标

继续补齐对标马帮后的生产级能力，重点处理文件资料安全、对象存储访问、员工账号治理和权限审计。

## 已完成

- 客户上传资料接口完成中文化，并记录 `document_upload` 审计日志。
- 员工代客户上传资料接口完成中文化，并记录上传人、客户、单据、扫描状态和存储方式。
- 文件下载接口保留登录/安全 token 校验，新增 `document_download` 审计日志。
- 文件预览接口保留登录、客户隔离、扫描状态、预览类型限制，新增 `document_preview` 审计日志。
- 文件安全台账导出完成中文化，支持客户、扫描状态、存储方式筛选，CSV 包含中文标签和代码字段。
- 员工账号管理底层完成中文化，统一密码策略：至少 8 位且同时包含字母和数字。
- 员工账号 API 完成中文化，保留敏感操作二次确认，并禁止管理员禁用或直接修改当前登录账号角色。
- 员工自助修改密码接口完成中文化和审计。
- 员工准入与权限审计报表完成中文化，覆盖白名单、角色权限、敏感操作二次确认和审批规则。

## 生产价值

- 文件上传、预览、下载都能审计到人，后续可追踪客户资料和财务附件访问记录。
- 对象存储、外部病毒扫描、基础扫描已形成统一资料安全链路。
- 员工账号从白名单过渡到可管理账号体系，具备邀请、启用、禁用、密码修改、角色变更审批和审计导出能力。

## 仍需继续

- 正式对象存储接入后，需要配置 `OBJECT_STORAGE_UPLOAD_URL` / `OBJECT_STORAGE_DOWNLOAD_URL` 或 Vercel Blob 相关环境变量。
- 如果要做更强安全，可继续接入异步扫描队列、大文件分片上传、下载短链失效策略和更细的员工操作审批流。
