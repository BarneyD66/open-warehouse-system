# Pass 175 - 深层 WMS 规则合规看板

## 背景

系统已经具备库位、容量、批次、效期、序列号、冻结库存、残次品库存、风险巡检和报表导出能力，但这些风险分散在多个页面。对标马帮类 WMS，仓库主管需要一个集中看板快速判断库位、批次和库存控制是否符合日常作业规则。

## 本次新增

- 新增 `OpsWmsRuleCompliancePanel`。
- 在运营后台库存模块中接入“深层 WMS 规则合规看板”。
- 汇总展示：
  - 有效 WMS 策略数量。
  - 待确认策略数量。
  - 库位容量/混放风险数量。
  - 批次/效期/序列号风险数量。
  - 冻结、残次、低库存、库龄风险数量。
- 支持一键执行：
  - 批次风险巡检：调用 `/api/ops/inventory-lots/risk-review`。
  - 库位风险巡检：调用 `/api/ops/warehouse/locations/risk-review`。
- 提供库位、批次、库存三个报表导出入口。

## 产品价值

- 仓库主管不用分散查看库位列表、批次台账和库存表，进入库存模块即可看到深层 WMS 风险。
- 风险巡检结果会复用现有工单链路，让临期、过期、停用库位占用、超容量等问题进入运营处理闭环。
- 让系统更接近可日常使用的 WMS，而不只是库存数据登记。
