# Pass 198 - 运营财务调账/赔付看板

## 本轮目标

把财务复核、费用调账和赔付抵扣从报表导出能力进一步前置到运营财务总控页，方便员工每天直接看到处理优先级。

## 已完成

- 运营财务总控新增财务复核工单数量。
- 新增调账/赔付记录数量和调账/赔付净额。
- “今日优先处理”列表纳入财务复核工单。
- “今日优先处理”列表纳入调账/赔付记录，并显示来源工单和原账单。
- 财务关账检查增加调账/赔付摘要。
- 运营后台向财务总控组件传入客户工单数据。

## 业务价值

财务人员不需要先进入报表下载或工单列表才能发现费用争议，运营后台一打开就能看到哪些工单待复核、哪些调账/赔付已经生成、净额对本期财务有什么影响。

## 下一步

- 继续补账单争议处理进度时间线。
- 将调账/赔付审批状态进一步细化为待审批、已审批、已入账。
