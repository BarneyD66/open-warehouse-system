# Pass 181 - API 事件自动告警联动

## 背景

Pass 180 已经把承运商、平台、Webhook、自动任务和审计日志汇总成 API 联调事件台账。本轮继续把台账风险接入系统告警，让接口失败不再只停留在报表里，而是自动进入运营总览、上线守卫和告警处理流程。

## 本轮完成

- 扩展 `getSystemAlerts()` 的数据源。
  - 新增 Webhook 事件读取。
  - 新增自动化运行记录读取。
  - 新增接口相关审计日志读取。

- 新增 API 风险告警生成规则。
  - Webhook 失败直接生成严重告警。
  - Webhook 处理中超过 10 分钟生成告警，超过 30 分钟升级为严重。
  - 自动化子任务失败或权限不足生成告警，权限不足按严重处理。
  - 接口探测、承运商面单、轨迹/POD、平台拉单、取消复核、发货回传等审计日志出现失败/异常/错误时生成告警。

- 复用现有告警处理能力。
  - 告警可以继续使用确认、搁置、关闭、重新打开。
  - 告警会自动进入运营后台总览、上线守卫、系统日志。
  - 不额外增加一套状态表，避免重复维护。
