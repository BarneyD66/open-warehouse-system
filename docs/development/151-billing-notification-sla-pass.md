# 151 账单通知与 SLA 提醒优化

## 本轮目标

把费用、账单、付款复核和争议处理纳入消息中心和 SLA 提醒，让客户、运营、财务和老板都能直接看到下一步要处理什么。

## 已完成

- 客户侧消息中心新增账单待确认、账单待付款、付款凭证已提交、账单异议处理中提醒。
- 客户侧账单提醒支持到期日、三天内到期、逾期天数和 SLA 等级。
- 员工侧消息中心新增付款凭证待财务复核、账单异议待处理、客户账单逾期、客户账单即将到期提醒。
- 争议、逾期和付款待复核可按通知订阅配置生成邮件投递记录，站内信仍默认可见。
- 通知中心 UI 显示发生时间、SLA 状态和通知渠道，方便按优先级处理。

## 使用价值

- 客户登录后能清楚知道账单是否要确认、付款或等待复核。
- 财务能直接看到付款凭证和逾期账单，不需要反复翻账单列表。
- 运营和老板能从消息中心判断哪些客户账单已经进入风险状态。
