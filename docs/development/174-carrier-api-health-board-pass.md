# Pass 174 - 承运商 API 闭环看板

## 背景

系统已经具备承运商规则、真实/沙箱网关、面单购买、面单取消、面单失败自动重试、轨迹/POD 同步、派送异常、签收证明和赔付记录。但运营后台缺少一个集中视图来判断承运商闭环是否健康。

## 本次新增

- 新增 `OpsCarrierHealthPanel`。
- 在运营后台物流模块中接入“承运商 API 闭环看板”。
- 汇总展示：
  - API 型承运商渠道数量。
  - 渠道配置缺口数量。
  - 面单失败数量。
  - 轨迹/POD 待同步数量。
  - 派送异常和赔付事项数量。
- 增加运营动作：
  - 重试到期面单：调用 `/api/ops/carrier-labels/retry-due`。
  - 同步轨迹/POD：调用 `/api/ops/carrier-tracking/sync-due`。
- 展示渠道配置缺口、面单失败原因、最近轨迹、开放派送异常和赔付状态。

## 产品价值

- 承运商 API 能力从“接口链路存在”升级为“运营可看、可重试、可追责”的闭环。
- 老板可快速看到真实发货链路是否卡在面单、轨迹、签收证明或赔付。
- 与既有承运商网关、面单重试、轨迹同步和异常赔付能力复用，避免重复实现。
