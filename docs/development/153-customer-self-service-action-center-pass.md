# 客户自助操作中心开发记录

## 背景

对标马帮后，客户侧已经具备库存、出库、费用、面单、签收证明、异常、退货和资料归档下载能力，但客户登录后仍需要在多个模块之间寻找下一步动作。本轮补齐“客户自助能力升级”的汇总层，让客户一进工作台就能看到待确认、待付款、异常确认、退货处理、可下载面单/签收证明和工单沟通。

## 本轮新增

- 新增客户自助操作中心规则：`src/lib/customerSelfServiceCenter.ts`
  - 汇总入库缺资料、缺追踪号。
  - 汇总账单待确认、待付款、付款待复核、争议、逾期。
  - 汇总可下载面单、签收证明、物流异常确认。
  - 汇总退货处理方式待确认。
  - 汇总客户工单待补充和运营回复。
  - 汇总库存低库存、冻结、残次、库龄风险。
- 新增客户侧 API：`/api/self-service/actions`
  - 默认返回 JSON。
  - `?format=csv` 返回中文字段 CSV：`客户自助操作清单-客户编号.csv`。
- 扩展原下载中心：`/api/downloads?kind=self-service-actions`
  - 与页面共用同一套规则，避免页面和下载清单不一致。
  - 加入资料包索引统计。
- 新增客户工作台面板：`CustomerSelfServiceActionPanel`
  - 显示待处理事项、紧急事项、可下载资料、异常/风险。
  - 每条事项提供“去处理”和“下载”入口。
  - 紧急事项出现时给出优先处理提示。
- 更新客户工作台 `/portal`
  - 将“我的操作清单”放在总览指标后、异常中心前。
  - 下载中心新增“自助操作清单”。

## 客户体验变化

客户登录后不用先判断该点哪个模块。系统会直接告诉客户：

- 哪些入库资料或追踪号需要补；
- 哪些账单需要确认、付款或等待复核；
- 哪些物流异常需要客户确认处理意见；
- 哪些退货需要确认重新上架、维修、报废或转寄；
- 哪些面单和签收证明可以直接下载；
- 哪些库存风险需要关注；
- 哪些工单需要补充信息或查看运营回复。

## 后续建议

- 将操作清单接入站内信未读状态，客户处理后自动减少待办。
- 为高优先级事项增加邮件、短信或微信通知。
- 给每类事项增加 SLA 倒计时和超时升级记录。
- 在客户侧增加“已处理/忽略”视图，方便客户复盘历史操作。
