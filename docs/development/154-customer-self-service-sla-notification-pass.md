# 客户自助 SLA 与通知闭环开发记录

## 背景

上一轮已经把客户待处理事项汇总成“我的操作清单”。本轮继续补齐消息中心和 SLA 提醒闭环，让客户自助事项不仅能在页面展示，也能被通知中心、投递队列和运营生成任务识别。

## 本轮新增

- 客户自助事项增加 SLA 字段：
  - `slaLevel`：正常跟进、即将超时、已超时。
  - `dueAt`：事项截止时间。
  - `overdueHours`：超时小时数。
  - `reminderChannels`：建议提醒渠道。
- 自助操作清单 CSV 增加中文字段：
  - SLA 状态、截止时间、超时小时、建议通知渠道。
- 客户工作台“我的操作清单”增加 SLA 标签：
  - 已超时、即将超时、正常跟进。
  - 展示截止时间。
  - 紧急提示文案说明超时事项会进入站内信和邮件提醒队列。
- 客户通知中心接入自助事项摘要：
  - 有待处理事项时生成“自助待办摘要”。
  - 有紧急或超时事项时，摘要为紧急通知。
  - 超时/紧急摘要会建议站内信和邮件渠道。
- 通知 API 和定时生成接口补齐客户资料上下文：
  - `/api/notifications` 客户侧获取通知时传入客户资料归档。
  - `/api/ops/notifications/generate-due` 扫描客户时按客户过滤资料与工单。
- 运营生成任务返回与审计日志增加：
  - `customerSelfServiceDigest`
  - `customerSelfServiceOverdue`

## 当前效果

客户登录后，既能在工作台看到自助操作清单，也能在消息中心看到自助待办摘要。运营或定时任务触发通知生成后，系统会把带邮件渠道的紧急/超时摘要写入通知投递队列，并在操作日志里记录生成数量。

## 后续建议

- 将自助事项处理完成后的状态回写到通知已读/关闭，减少重复提醒。
- 为短信、微信渠道接入正式供应商 webhook。
- 在运营后台增加“客户自助待办摘要”筛选视图。
- 增加 SLA 配置中心，让 12/24/48 小时阈值可由运营配置。
