# Pass 200 - 调账/赔付审批状态字段

## 本轮目标

把费用调账和赔付抵扣的审批/入账状态从报表推断升级为账单数据字段，方便后续做审批流、统计和客户展示。

## 已完成

- 新增 `BillingAdjustmentApprovalStatus`：
  - `pending_approval`
  - `approved`
  - `posted`
  - `rejected`
  - `paid`
- `BillingRecord` 新增 `adjustmentApprovalStatus`。
- 财务复核生成调账/赔付账单时写入初始审批/入账状态。
- 员工后续更新账单状态时，会同步刷新调账/赔付审批状态。
- 财务调账/赔付审批报表优先读取真实状态字段。
- 客户账单页、客户月结单页、运营财务总控展示调账/赔付状态。
- 客户账单 CSV 导出新增“调账/赔付状态”字段。

## 业务价值

调账/赔付不再只是一个负数账单，而是有明确状态：待审批、已审批、已入账、已驳回/有争议、已核销。后续可以继续扩展审批流、附件校验和老板端统计。

## 下一步

- 将审批附件和审批规则命中结果写入时间线。
- 在运营后台提供按状态筛选的调账/赔付审批列表。
