# 228 上线守门板接入生产集成验收

## 本轮目标

- 让上线守门板不仅检查生产集成配置，还能检查集成项是否完成联调验收。
- 避免「配置看起来可上线，但没有实际探测记录」的集成被遗漏。

## 已完成

- `launchGuard` 支持接收生产集成验收报告。
- 上线守门板新增「生产集成验收」任务来源。
- 配置可上线但未完成探测的集成项会进入关注项。
- 探测失败的集成项会进入阻塞项。
- 配置本身未 ready 的集成项仍由「生产集成配置」任务提示，避免重复展示。
- `/api/ops/launch-guard` 会计算并返回生产集成验收评分。
- 运营后台上线守门板、JSON 接口和 CSV 导出共用同一套逻辑。
- 报表中心生成上线风险时也会包含生产集成验收状态。

## 验证

- `npm run lint`：通过。
- `npm run build`：通过。
- Next 构建路由表保持 `/api/ops/launch-guard` 和 `/api/ops/reports/integration-acceptance` 可用。

## 下一步

- 后续可在上线守门板里增加一键跳转到对应集成探测按钮。
