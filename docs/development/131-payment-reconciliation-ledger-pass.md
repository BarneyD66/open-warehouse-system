# 131. 收款核销台账补强

## 本轮范围

- 新增运营报表：`/api/ops/reports/payment-reconciliation`。
- 支持按月份、客户编号、核销状态、风险等级、关键词筛选。
- 支持 CSV 导出和 `format=json`，表头和字段以中文为主。
- 报表行包含客户结算周期、账期天数、信用额度、月结单、付款参考号、提交付款时间、核销时间、驳回原因、争议说明、风险等级和下一步处理建议。
- 运营后台报表中心新增“导出收款核销”入口。
- 保存视图支持 `payment_reconciliation` 模块，按视图导出时会路由到收款核销台账。
- 定时报表执行也支持 `payment_reconciliation`，可按计划发送收款核销台账下载链接。

## 生产化价值

- 财务可以清晰区分已核销、待财务复核、争议处理中、已驳回待重提、已确认待付款、待客户确认等状态。
- 老板能从同一张台账看到逾期、争议、客户信用额度超限等风险。
- 该报表可被保存视图和定时报表复用，适合作为月结收款日常工作表。
