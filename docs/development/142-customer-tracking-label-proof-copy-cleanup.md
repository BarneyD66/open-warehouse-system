# 客户业务进度、面单和签收证明中文清理

## 本次目标

客户可见的业务进度页、面单页和签收证明接口需要保持中文可读，避免客户下载面单或查看物流进度时出现乱码。

## 已完成

- 重写客户业务进度页 `/tracking`，清理报价、入库、出库、物流、库存、面单和签收证明相关文案。
- 重写客户/员工可访问的面单接口 `/api/outbounds/[id]/label`，内部面单 HTML 恢复中文字段和打印按钮。
- 重写签收证明接口 `/api/outbounds/[id]/proof`，登录、权限、未签收、未回传证明等提示恢复中文。
- 保留原有客户隔离权限：客户只能查看自己客户编号下的出库单、面单和签收证明。
