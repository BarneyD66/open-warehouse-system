# 205 财务审批默认保存视图

## 本轮目标

把财务调账/赔付常用筛选从“页面快捷链接”升级为系统默认保存视图，便于报表中心、保存视图导出和定时报表共用同一套配置。

## 已完成

- 在运营扩展数据层增加系统默认保存视图：
  - 财务调账/赔付-待审批。
  - 财务调账/赔付-附件待补。
  - 财务调账/赔付-争议待复核。
  - 财务调账/赔付-付款待核销。
- 读取运营扩展数据时自动合并默认视图，避免新环境或 Vercel 临时存储里缺少基础视图。
- 默认视图使用稳定 ID，支持通过 `/api/ops/reports/views/{id}` 导出。
- 报表中心的财务审批常用视图改为走保存视图导出接口，而不是临时拼报表参数。

## 价值

财务人员进入系统后不需要先手动配置视图，就能直接导出待审批、缺附件、争议、待核销清单；后续定时报表也可以直接选择这些默认视图。

## 后续建议

- 为关键默认视图提供“一键创建定时报表”按钮。
- 将更多高频运营视图纳入系统默认视图，例如出库异常、承运商面单失败、平台同步失败、库存低于预警。
