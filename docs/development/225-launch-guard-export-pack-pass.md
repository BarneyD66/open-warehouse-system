# 225 上线复核包导出

## 本轮目标

- 把上线守门板从页面看板升级成可下载、可留档、可分派的上线复核包。
- 让老板、运营、仓库和技术负责人可以拿同一份清单确认「能不能上线、谁负责、下一步做什么」。

## 已完成

- 新增 `launchGuard` 纯逻辑模块，统一生成上线守门任务。
- 上线守门任务合并以下来源：
  - 上线体检
  - 生产集成配置
  - 系统健康检查
  - 系统告警
- 新增 `/api/ops/launch-guard` JSON 接口。
- 新增 `/api/ops/launch-guard?format=csv` 中文 CSV 导出。
- 运营后台「上线守门板」新增「导出复核包」按钮。
- 前端上线守门板和导出接口复用同一套任务生成逻辑，避免页面和导出结果不一致。

## 导出字段

- 生成时间
- 总体结论
- 总评分
- 阻塞项
- 关注项
- 来源
- 状态
- 负责人
- 事项
- 详情
- 下一步动作
- 处理入口
