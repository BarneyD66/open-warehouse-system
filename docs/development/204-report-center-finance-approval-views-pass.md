# 204 报表中心财务审批常用视图

## 本轮目标

让财务调账/赔付审批不只存在于账单页，也能从报表中心快速进入日常固定筛选，便于财务每天按清单处理。

## 已完成

- 报表中心新增“财务审批常用视图”区块。
- 固定提供四个高频导出入口：
  - 待审批调账/赔付。
  - 附件待补。
  - 争议待复核。
  - 付款待核销。
- 报表中心的财务调账/赔付风险口径优化为只统计待处理记录，不再把所有已完成调账都算作风险。
- 风险说明改为“财务复核/调账赔付待处理”，更贴近日常运营判断。

## 价值

老板和财务人员进入运营后台后，可以在报表中心直接看到财务审批堵点，并一键导出对应清单，日常使用路径更短。

## 后续建议

- 将这四个固定视图自动初始化为保存视图，允许配置定时发送。
- 在报表中心支持按角色展示快捷视图，例如财务、仓库、客服各自默认不同入口。
