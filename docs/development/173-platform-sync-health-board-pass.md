# Pass 173 - 平台同步健康看板

## 背景

对标马帮的多平台订单同步能力，系统已经具备平台连接配置、API/CSV 拉单、同步任务记录、平台取消订单复核、发货追踪号回传和回传失败重试接口。但这些能力分散在不同按钮和记录里，运营日常需要一个集中看板判断平台链路是否健康。

## 本次新增

- 新增 `OpsPlatformSyncHealthPanel`。
- 在运营后台出库模块中接入平台同步健康看板。
- 汇总展示：
  - API 型平台连接数量。
  - 到期未拉单连接数量。
  - 连接异常和同步失败数量。
  - 平台取消订单待复核数量。
  - 发货追踪号待回传/回传失败数量。
  - 出库单缺少匹配店铺连接的风险。
- 增加三个运营动作：
  - 同步到期平台订单：调用 `/api/ops/platform-orders/sync-due`。
  - 复核平台取消订单：调用 `/api/ops/platform-orders/cancellation-review`。
  - 重试发货回传：调用 `/api/ops/platform-fulfillment/retry-due`。

## 产品价值

- 平台 API 同步从“接口可用”变成“运营可看、可点、可追”的日常工作台。
- 老板和运营可以直接看到平台链路风险：拉单失败、取消未处理、追踪号未回传、店铺连接缺失。
- 与现有平台网关、同步任务、取消复核和发货回传重试能力复用，避免重复状态机。
