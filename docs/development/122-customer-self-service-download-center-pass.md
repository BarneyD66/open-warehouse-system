# 122 客户自助下载中心优化

## 背景

对标马帮的客户自助能力，客户侧不仅要能提交需求和查看状态，也需要清晰下载库存、出库、面单、签收证明、费用和异常售后资料。原工作台已有 `/api/downloads` 导出能力，但页面入口集中在一块较小区域，客户不容易判断每个下载项对应什么业务。

## 本次完成

- 将客户工作台的“自助模板与服务资料”升级为“客户自助下载中心”。
- 按资料索引、库存报表、出库物流、费用账单、异常售后分组展示下载项。
- 每个下载项展示中文名称、用途说明、当前关联数据量和下载入口。
- 保留模板文件和工单类型入口，方便客户下载模板后继续提交资料或异常工单。
- 去掉旧的“按中文文案猜下载类型”跳转逻辑，改为固定 `kind` 下载参数，避免文案调整导致导出链接错配。

## 覆盖下载项

- 资料包索引
- 库存报表、库龄分析、库存流水、进销存报表、批次效期库存
- 出库明细、出库复核状态、面单列表、签收证明
- 费用明细
- 我的异常中心、物流异常与赔付、退货质检明细
