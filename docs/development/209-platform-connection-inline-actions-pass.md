# 209 平台连接行内操作

## 本轮目标

把平台订单 API 同步从“批量执行任务”继续推进到“单店铺可日常管理”，方便运营处理某个具体店铺的异常、暂停和恢复。

## 已完成

- 平台同步健康看板新增单店铺连接操作。
- 每个 API 平台连接支持：
  - 立即同步该店铺订单。
  - 暂停该店铺连接。
  - 恢复该店铺连接。
- 看板新增“已暂停”统计。
- 平台连接列表会优先展示异常、到期、暂停连接，再补充其他 API 连接。
- 单店铺同步复用现有 `/api/ops/platform-orders/sync-due`，并指定 `connectionId` 与 `minIntervalMinutes=0`。
- 暂停/恢复复用现有平台配置保存接口，保留字段映射、同步模式和备注。

## 价值

运营人员可以直接在健康看板里处理单个 Amazon、TikTok Shop、Shopify、eBay 店铺，不必回到配置表单重新维护整条连接，平台同步日常可用性更强。

## 后续建议

- 增加单店铺同步历史抽屉，展示最近同步任务、预检批次和失败原因。
- 增加连接凭证体检按钮，区分缺 token、接口地址错误和平台返回权限错误。
- 将平台连接状态变更写入独立审计日志。
