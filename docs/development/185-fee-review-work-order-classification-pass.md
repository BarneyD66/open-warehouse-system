# 185 费用复核工单分类闭环

## 本轮目标

把客户侧“物流费用差异复核/账单争议”从普通客服工单升级为运营后台可识别、可分派给财务处理的结构化工单。

## 已完成

- 客户工单数据模型新增 `riskTag`、`financeReviewRequired`、`linkedDownloadHref` 等字段。
- 客户提交工单 API 会自动识别账单争议、物流费用、运费差异、物流证据包等关键词。
- 物流费用复核会自动升级为紧急工单，并标记为“财务复核 + 运费差异”。
- 账单争议会自动升级为紧急工单，并标记为“财务复核 + 账单争议”。
- 运营后台客户自助工单处理队列新增财务复核标签、风险标签、内部提示和证据/账单入口。

## 对标马帮价值

- 费用类问题不再混在普通客服消息里，运营和财务能更快识别处理责任。
- 客户提交复核后，后台能直接引导查看物流证据包、承运商实际费用和月结账单。
- 为后续账单争议审批、付款核销、赔付和客户确认闭环打基础。

## 下一步建议

- 将费用复核工单进一步关联到具体账单记录或出库单。
- 在财务账单页增加“待复核工单”筛选。
- 增加复核结论字段，例如同意调整、维持原账单、需补充证据。
