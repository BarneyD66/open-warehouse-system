# Pass 201 - 调账/赔付规则与附件审计

## 本轮目标

把财务调账/赔付审批中的规则命中结果和附件归档状态从临时校验升级为可展示、可导出、可追溯的数据字段。

## 已完成

- `BillingRecord` 新增调账/赔付审批规则字段：
  - `adjustmentApprovalRuleId`
  - `adjustmentApprovalRuleName`
  - `adjustmentApprovalRuleNote`
  - `adjustmentAttachmentStatus`
- 财务复核生成调账/赔付时，会写入命中的审批规则、规则说明和附件状态。
- 附件状态区分：
  - 不要求附件
  - 附件已归档
  - 附件已确认
  - 附件待补
- 调账/赔付时间线事件会附带审批规则和附件状态。
- 财务调账/赔付审批报表新增审批规则、规则说明和附件状态字段。
- 客户账单页、客户月结单页展示审批规则和附件状态。
- 客户账单 CSV 导出新增审批规则、规则说明和附件状态。
- 运营财务总控的调账/赔付摘要展示附件状态。

## 业务价值

调账和赔付不仅能看到金额和状态，还能追溯“为什么需要审批”“由哪条规则审批”“附件是否已经归档”。这对正式运营后的财务审计、客户争议复盘和老板检查都很关键。
