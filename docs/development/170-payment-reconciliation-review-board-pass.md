# 170 银行流水核销人工复核队列

## 本轮目标

继续补齐费用与财务实账能力。现有系统已经支持银行流水 CSV 导入、自动核销和核销批次导出，但财务日常还需要清楚看到哪些流水被系统跳过、为什么跳过、下一步应该怎么处理。本轮把导入后的“人工复核队列”补到运营后台。

## 已完成

- 运营后台账单模块新增“银行流水人工复核队列”：
  - 汇总自动核销行数、待复核行数、已核销金额。
  - 展示最近待复核流水行。
  - 展示批次号、行号、到账金额、币种、客户编号、银行流水号、付款参考号和付款方。
  - 展示跳过原因和财务建议动作。
- 新增复核建议规则：
  - 金额不一致：提示核对到账金额、账单金额和部分付款。
  - 争议账单：提示先处理账单争议。
  - 多候选：提示人工确认唯一账单或月结单。
  - 非 GBP/币种问题：提示确认币种和汇率口径。
  - 未找到匹配：提示按客户、付款参考号、银行流水号继续检索。
- 运营接口新增批次 JSON 明细：
  - `GET /api/ops/mabang-modules?batchId=...&report=payment-reconciliation-json`
  - 返回批次汇总、待复核行和已核销行。
  - 为后续弹窗详情页、独立财务核销页或外部对接留接口。

## 产品效果

- 财务导入银行流水后，不只看到“成功/跳过”数字，还能直接看到待复核明细。
- 老板和运营可以判断待复核金额、待复核原因和财务下一步动作。
- 自动核销仍保持保守策略，避免金额不一致、多候选、争议账单被误核销。
