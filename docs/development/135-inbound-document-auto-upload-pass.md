# 135 入库预报附件自动归档到资料中心

## 本轮目标

客户创建入库预报时，如果选择了装箱单、SKU 清单、外箱标签、物流面单等附件，系统不能只记录文件名，而要把文件本体同步进入正式资料中心，方便运营审核、下载、预览和安全留痕。

## 已完成

- 客户入库预报表单创建 ASN 成功后，会自动把所选文件逐个上传到 `/api/documents`。
- 文件统一关联到：
  - 关联类型：`inbound`
  - 关联单号：新创建的入库预报编号
  - 文件分类：`packing_list`
  - 上传角色：客户
- 文件会复用现有资料中心能力：
  - 文件大小限制
  - 基础安全扫描
  - 外部病毒扫描 webhook
  - 对象存储 / 数据库 / 本地兜底
  - 资料中心预览、下载、安全状态展示
- 成功页新增上传结果提示：
  - 文件全部成功：提示已同步上传，运营可在资料中心查看。
  - 文件上传失败：保留入库预报成功结果，同时明确提示附件失败，客户可后续到补交资料页重新上传。

## 产品价值

这解决了一个很关键的真实使用问题：客户以为上传了资料，但运营后台只能看到文件名。现在资料会真正进入资料中心，运营审核入库预报时可以直接查文件、安全状态和关联单据，老板也能从资料安全报表里看到完整留痕。

## 后续建议

- 在入库预报详情卡片里直接展示该 ASN 已上传的资料数量和快捷预览入口。
- 对缺少核心资料的入库单自动生成运营待办。
- 将询盘阶段的附件也接入资料中心，作为 `general` 或 `inquiry` 资料归档；当前资料模型还没有 `inquiry` refType，可后续扩展。
