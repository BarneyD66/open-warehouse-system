# 158 平台取消订单复核闭环

## 背景

对标马帮的平台订单同步能力，系统已经具备平台拉单、同步记录、取消订单识别、平台发货回传和取消 webhook 处理。本轮补齐“平台同步任务拉到取消/作废订单后”的自动处理闭环，避免取消记录只停留在报表提醒里。

## 本轮完成

- 新增 `reviewPlatformCancelledOrders` 业务能力：
  - 扫描最近平台同步任务中的取消/作废订单。
  - 自动匹配客户、平台、店铺和平台订单号对应的出库单。
  - 未匹配出库单时生成“平台取消订单未匹配出库单”运营核查工单。
  - 未发货出库单自动生成运营工单，并申请截单；如已有面单或追踪号，先尝试取消面单。
  - 已发货出库单不强行改状态，转为派送/退回异常，并生成售后跟进工单。
  - 已进入截单流程或已有未关闭异常时跳过重复创建。
- 新增 API：
  - `POST /api/ops/platform-orders/cancellation-review`
  - 支持员工 `admin/ops` 调用，也支持 `PLATFORM_CANCELLATION_REVIEW_SECRET`、`PLATFORM_ORDER_SYNC_SECRET` 或 `CRON_SECRET` 定时任务调用。
- 接入生产自动化调度：
  - `/api/ops/automation/run-due` 在平台订单同步后自动执行取消订单复核。
  - `/api/ops/automation/task-actions` 支持失败子任务重试。
- 运营后台马帮对标模块新增按钮：
  - `复核平台取消订单`
  - 执行后展示复核数、截单数、异常数、工单数和失败数。
- 生产集成就绪检查新增：
  - `PLATFORM_CANCELLATION_REVIEW_SECRET`
  - 提醒调度器调用取消订单复核接口。

## 价值

平台订单取消后，系统会自动推动仓库截单、面单取消、库存释放或售后异常处理，形成“平台变更 -> 仓库动作 -> 运营工单 -> 审计记录”的闭环。
