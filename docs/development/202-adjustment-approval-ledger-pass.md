# 202 调账赔付审批台账与附件入口

## 本轮目标

把上一轮已经写入数据层的调账/赔付审批状态、审批规则、附件状态，真正放到运营后台可操作的位置，避免财务人员只能依赖导出表处理。

## 已完成

- 在运营后台账单争议复核模块新增“调账/赔付审批台账”。
- 支持按调账类型、审批/入账状态、附件状态筛选。
- 支持导出当前筛选结果，导出参数会带上审批状态和附件状态。
- 每条调账/赔付记录展示客户、金额、来源工单、来源账单、审批规则、附件状态和审批时间线。
- 每条记录提供审批附件上传入口，复用员工文件上传与安全扫描能力。
- 财务复核工单卡片增加审批附件上传入口，引用规则为 `approval / 工单ID`。
- 财务调账/赔付报表接口增加 `approvalStatus` 和 `attachmentStatus` 过滤，并写入审计日志。

## 价值

财务人员现在可以在后台直接看到哪些调账/赔付待审批、哪些缺附件、哪些已入账或已核销；老板/管理者也能通过同一个台账追溯审批规则和处理进度。

## 后续建议

- 将调账/赔付台账进一步拆成独立页面，支持分页、批量导出和保存视图。
- 对“附件待补”的记录生成 SLA 提醒，自动推送给负责员工。
- 把审批动作从当前账单状态流里拆成独立审批单，支持多级审批。
