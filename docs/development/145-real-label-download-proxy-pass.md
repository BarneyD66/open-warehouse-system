# 145 真实面单下载与内部打印预览

## 本轮目标

把真实承运商面单从简单外链跳转升级为系统内鉴权后的可预览、可下载链路，同时清理内部打印页遗留乱码。

## 已完成

- `/api/outbounds/[id]/label` 继续要求客户或员工登录。
- 客户只能查看自己客户编号下的出库面单，员工可查看运营范围内面单。
- 已生成的真实 PDF/ZPL 面单会优先由系统服务端代理读取并返回，保留 `no-store` 和 `nosniff` 头。
- 如果承运商签名链接无法由服务端读取，会回退到 302 跳转，保证现场打印不断流。
- 内部面单 HTML 完整中文化，包含客户、模式、波次、篮号、订单数、重量、件数、费用和追踪号。
- 仓库内部 `/warehouse/print/label/[id]` 预览页完成中文化，并区分系统内部面单、承运商 PDF、承运商 ZPL。

## 验证重点

- 未登录访问面单会返回 401。
- 客户访问其他客户的面单会返回 403。
- 未生成面单的出库单会返回 404。
- 真实承运商面单可通过同一个系统链接打开，不需要员工复制第三方链接。
