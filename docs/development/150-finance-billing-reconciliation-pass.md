# 150 财务实账与收款核销优化

## 本轮目标

对标马帮的费用、账单、月结和收款核销能力，把当前工作台里影响日常财务使用的关键链路补齐到可操作、可追溯、可导出。

## 已完成

- 自动计费生成接口增加员工账单权限校验、限流和审计日志。
- 自动计费覆盖出库基础处理、SKU 件数、面单贴标、燃油附加费、偏远地区附加费、超尺寸/多包裹附加费、退货质检、退货上架、退货销毁、仓储日租。
- 账单复核接口统一中文错误提示，并补齐状态复核、付款复核、开票复核的操作日志。
- 运营端账单复核组件修复中文文案，明确保存复核、确认到账、驳回付款、解除异议、重新打开。
- 费用事件台账、收款核销台账、应收账龄报表全部改为中文字段、中文文件名和中文下一步建议。
- 核心费用规则、账单状态、开票状态、月结锁定/解锁说明统一为中文口径。

## 使用价值

- 财务可以按客户、月份和状态导出费用明细，直接核对收费来源。
- 运营可以自动生成常见仓储/物流费用，减少手工漏算。
- 老板可以从审计日志追溯谁生成了费用、谁确认到账、谁驳回付款凭证。
- 客户账期、逾期、争议、付款待复核会在报表里形成清晰风险提示。
