# 136 资料上传链路中文文案清理

## 本轮目标

修复资料上传相关页面和接口里的历史乱码文案，保证客户和员工在中文模式下看到的是清晰中文。

## 已完成

- 清理 `DocumentUploadPanel` 可见文案：
  - 未选择文件提示
  - 上传失败提示
  - 文件说明占位文案
  - 上传、预览、下载、暂无文件按钮和空状态
- 清理客户资料上传接口 `/api/documents` 的错误返回：
  - 上传频繁
  - 未选择文件
  - 不支持关联类型 / 文件分类
  - 关联单据编号缺失
  - 空文件
  - 文件大小超限
  - 上传失败兜底
- 清理运营资料上传接口 `/api/ops/documents` 的错误返回。
- 清理资料状态标签：
  - 数据库归档
  - 本地文件
  - 对象存储
  - 未记录
  - 待扫描 / 已通过 / 已拦截

## 产品价值

资料上传是客户提交入库、财务凭证、异常照片和运营审批附件的基础入口。文案清晰后，客户不会因为乱码误判系统异常，员工也能更快判断文件存储状态和安全扫描状态。

## 验证

- 已用 `rg` 检查本轮涉及文件，没有发现真实乱码字符残留。
- 后续随本轮整体执行 `npm run lint` 和 `npm run build`。
