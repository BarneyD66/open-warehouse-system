# Pass 199 - 账单争议时间线与审批状态细分

## 本轮目标

把客户账单争议、付款、开票、财务复核、调账和赔付串成一条可见的处理进度，并补齐调账/赔付审批状态口径。

## 已完成

- 单条账单的客户确认、客户异议、提交付款、申请开票会写入 `approvalTimeline`。
- 月结单的客户确认、月结异议、月结付款、月结开票申请会写入 `approvalTimeline`。
- 员工确认到账、驳回付款、解除异议、重开账单、开票、作废发票会写入 `approvalTimeline`。
- 财务复核生成费用调账/赔付抵扣时，会在新账单中记录来源工单和来源账单的时间线事件。
- 新增通用 `BillingTimeline` 组件。
- 客户账单页展示每张账单处理进度。
- 客户月结单页展示月结处理进度。
- 运营账单争议复核队列展示账单处理进度。
- 财务调账/赔付审批报表新增“审批/入账状态”字段。
- 客户账单 CSV 导出新增“最近处理进度”字段。

## 业务价值

客户和员工都能看清一笔费用从客户提出异议、财务复核、生成调整到入账/核销的全过程。后续如果发生争议追溯，不需要翻聊天记录或人工解释。

## 下一步

- 继续细化调账/赔付的独立审批状态：待审批、已审批、已驳回、已入账。
- 将审批附件和审批规则命中情况展示到时间线。
