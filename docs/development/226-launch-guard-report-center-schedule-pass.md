# 226 上线复核包接入报表中心

## 本轮目标

- 将上线复核包从单独按钮升级为报表中心正式模块。
- 支持保存视图、最近导出、风险总览和定时报表发送链路。

## 已完成

- 新增报表模块 `launch_guard`。
- 新增系统默认保存视图 `SYS-VIEW-LAUNCH-GUARD`。
- 报表中心总览新增「上线复核包」模块。
- 报表中心风险统计接入上线守门任务：
  - 阻塞项按高权重计入风险。
  - 关注项计入关注风险。
- 报表中心页面新增「上线复核常用视图」区域。
- 支持从保存视图导出上线复核包：
  - `/api/ops/reports/views/SYS-VIEW-LAUNCH-GUARD`
- 支持定时报表发送上线复核包：
  - 调度器会生成 `/api/ops/launch-guard?format=csv&auditSource=scheduled_report`
- 直接导出上线复核包会写入审计和最近导出记录。

## 验证

- `npm run lint`：通过。
- `npm run build`：通过。
- Next 构建路由表包含 `/api/ops/launch-guard`。
