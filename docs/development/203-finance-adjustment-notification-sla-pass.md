# 203 调账赔付审批待办与 SLA 提醒

## 本轮目标

把调账/赔付从“后台能查到”继续推进到“员工会被提醒处理”，避免缺附件、待审批、待核销和争议记录沉在账单列表里。

## 已完成

- 优化员工待办生成逻辑，调账/赔付不再无差别推送。
- 仅对以下情况生成提醒：
  - 审批附件待补或未记录。
  - 审批待处理。
  - 付款待核销。
  - 争议/驳回待复核。
  - 已接近 SLA 或已超时。
- 提醒正文增加审批状态、附件状态、等待时长、来源工单、来源账单和审批规则摘要。
- 缺附件、超时、高金额或争议记录会升级为关键提醒，并可进入邮件投递队列。
- 通知生成接口摘要增加“财务复核缺附件”统计，便于运营后台和定时任务观察堵点。

## 价值

财务审批不再只靠人工翻表。员工待办中心会主动把需要处理的调账/赔付推出来，老板也能在通知生成摘要里看到缺附件和超时情况。

## 后续建议

- 将缺附件提醒联动到客户/员工消息中心，支持一键催补资料。
- 给调账/赔付审批单增加独立审批状态流，支持多级审批人流转。
- 在报表中心增加“财务审批 SLA”保存视图和定时发送。
