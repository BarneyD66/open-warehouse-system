# 162 生产日志检索中心

## 背景

对标马帮类系统的生产运维能力，系统已有系统告警、健康检查、备份恢复、任务重试、webhook 幂等和自动化运行记录。本轮补齐“生产日志检索中心”，让运营、老板和运维可以在一个入口快速查看错误、失败任务和关键审计记录。

## 已完成

- 扩展 `/api/ops/system/logs`：
  - 原有系统告警、批量任务、操作审计继续保留。
  - 新增承运商/平台 webhook 失败或处理中事件。
  - 新增生产自动化失败和权限不足子任务。
  - 支持按关键词、级别、来源、日期和数量筛选。
  - CSV 导出增加 webhook 与自动化日志来源。
- 新增运营后台“生产日志检索”面板：
  - 支持关键词搜索。
  - 支持按严重/提醒/信息筛选。
  - 支持按系统告警、任务队列、Webhook、自动化、审计筛选。
  - 支持刷新与导出。
  - 移动端使用纵向布局，日志内容自动换行。
- 总览页运维顺序调整为：系统告警 -> 生产日志检索 -> 生产健康检查 -> 备份恢复。

## 验收点

- webhook 失败不再只停留在 webhook 面板，可以进入统一日志检索。
- 自动化失败子任务可以和任务队列、审计记录放在同一时间线里查看。
- 运营能按单号、客户、错误原因、操作人搜索生产日志。
- 老的系统告警和健康检查不受影响。
