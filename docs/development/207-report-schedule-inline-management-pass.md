# 207 定时报表行内管理

## 本轮目标

补齐报表中心定时报表的日常管理动作，让运营不需要进入接口或额外配置页，也能直接管理已有计划。

## 已完成

- 报表中心数据结构增加定时报表原始字段：
  - 视图 ID。
  - 原始发送频率。
  - 收件人数组。
  - 原始启停状态。
- 新增 `ReportScheduleRowActions` 客户端组件。
- 每条定时报表支持：
  - 修改发送频率。
  - 修改收件人。
  - 保存配置。
  - 启用计划。
  - 暂停计划。
  - 立即执行该计划。
- 立即执行复用现有 `/api/ops/reports/schedules/run`，并展示发送、待配置和失败数量。
- 报表中心“定时报表状态”列表已接入行内动作。

## 价值

报表中心从“能看定时报表”升级到“能直接管理定时报表”，更接近马帮类运营后台的日常可用体验。

## 后续建议

- 增加删除/归档定时报表能力。
- 增加定时报表执行历史详情抽屉。
- 将更多高风险模块提供默认保存视图与一键定时发送。
