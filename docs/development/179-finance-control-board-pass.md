# 179 财务实账总控

## 本轮目标

对标马帮类系统的财务日常管控，把应收、逾期、付款核销、账单争议、客户信用额度、开票和月结锁定集中到运营后台账单模块。

## 已完成

- 新增 `OpsFinanceControlPanel`。
- 在运营后台账单模块接入“财务实账总控”。
- 汇总未结金额、逾期金额、待核销、争议账单、待开票、月结月份。
- 自动识别客户信用风险，区分信用阻塞和信用关注。
- 汇总今日优先处理队列，覆盖逾期应收、待核销、账单争议、待开票和信用风险。
- 增加应收账龄、核销台账、信用风险三个常用财务报表入口。
- 增加财务关账检查，提示付款核销、账期风险、发票/月结状态。

## 业务价值

- 财务每天先看一张面板即可知道哪些账会影响客户继续发货。
- 运营能看到信用阻塞客户，避免在逾期、预付欠款或信用超限时继续放行出库。
- 与现有账单生成、账单争议复核、付款核销、报表导出形成更清晰的日常闭环。
