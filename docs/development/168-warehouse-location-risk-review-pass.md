# 168 库位容量与规则风险巡检

## 本轮目标

继续补齐深层 WMS 仓库规则，把已有的库位容量、混放规则、冻结/残次品位和库存占用信息，从“能查看/能导出”推进为“可巡检、可生成工单、可审计、可自动化调度”的日常仓库闭环。

## 已完成

- 新增库位风险巡检业务能力：
  - 扫描全部库位和对应库存占用。
  - 识别停用库位仍有库存、预留库位已有库存、已超容量、接近满仓、未设置容量但已有库存。
  - 识别不允许混放 SKU 的库位出现多个 SKU。
  - 识别冻结库位存在普通/预留/残次库存、残次品位存在普通/预留/冻结库存、普通库位存在冻结或残次库存。
  - 为高风险或关注库位生成“库位风险”运营工单，避免只停留在报表里。
  - 同一库位已有未关闭工单时跳过重复创建。
- 新增 API：
  - `GET/POST /api/ops/warehouse/locations/risk-review`
  - 支持员工手动触发。
  - 支持 `WAREHOUSE_LOCATION_RISK_REVIEW_SECRET` 或 `CRON_SECRET` 定时触发。
  - 接入统一生产错误捕获。
- 新增审计动作：
  - `warehouse_location_risk_review_due`
  - 记录扫描库位数、复核数、高风险数、生成工单数和明细。
- 接入生产自动化：
  - `/api/ops/automation/run-due` 增加 `warehouse_location_risk_review` 子任务。
  - 可随平台同步、批量任务、批次风险、承运商重试、通知投递一起执行。
- 仓库库位管理面板新增“巡检库位风险”按钮，员工可以从页面直接触发。
- 顺手修复本轮涉及的中文乱码阻断文件：
  - 审计日志接口与审计日志面板。
  - 自动化调度接口。
  - 库位维护接口与库位管理面板。

## 产品效果

- 仓库负责人不只看到库位利用率，还能一键把风险转成待办工单。
- 超容量、混放违规、冻结/残次区误用等问题可以进入运营处理流。
- 老板和运营可以从审计日志、工单、自动化运行记录三处追踪库位风险处理情况。
