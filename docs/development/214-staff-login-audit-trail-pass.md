# 214 员工登录安全审计流水

## 本轮目标

继续补齐生产级员工账号与权限能力，让员工登录成功、失败和锁定风险进入可搜索、可导出的审计链路。

## 已完成

- 审计日志新增员工登录动作：
  - `staff_login_success`；
  - `staff_login_failed`。
- 员工登录成功时记录：
  - 员工账号；
  - 角色；
  - 进入后台路径；
  - IP 摘要；
  - User-Agent 摘要。
- 员工登录失败时记录：
  - 尝试账号；
  - 失败原因；
  - 连续失败次数；
  - 是否触发锁定；
  - IP 摘要；
  - User-Agent 摘要。
- 审计日志页面和导出接口补充员工登录成功/失败中文标签。
- 系统告警识别员工登录失败审计：
  - 普通失败为预警；
  - 触发锁定为关键告警。

## 产品价值

- 老板和管理员可以追踪员工账号的登录安全记录。
- 账号被爆破、误输导致锁定、异常来源登录失败都能进入审计查询。
- 权限模块从“账号可管理”继续升级为“账号可审计、风险可追踪”。

## 下一步建议

- 后续可以按 IP、账号、时间窗口聚合登录失败次数，形成更强的风控策略。
- 再进一步可增加 MFA、设备指纹和新设备登录提醒。
