# 191 财务复核调账和赔付记录

## 本轮目标

把费用复核从“关闭工单 + 回写备注”推进到“结构化复核结论 + 正式调账/赔付账单记录”。

## 已完成

- `BillingRecord` 新增 `adjustmentKind`、`adjustmentSourceRecordId`、`workOrderId` 等关联字段。
- 新增 `createManualBillingAdjustmentRecord`，可生成负数费用调账或赔付抵扣账单。
- 财务复核工单动作新增三种结论：
  - 维持原账单
  - 同意调账
  - 赔付抵扣
- 当财务点击“完成”且选择调账/赔付时，系统会生成一条已确认的负数账单记录。
- 调账/赔付记录会关联来源工单和原账单，审计日志会记录金额、结论和处理说明。
- 财务面板新增复核结论选择、金额输入，并展示已生成的调账/赔付账单。

## 对标马帮价值

- 账单争议处理不再只是文字备注，能形成正式财务记录。
- 客户费用异议、运费差异和物流赔付可以进入账单体系，后续支持月结抵扣、对账和审计。
- 财务可在同一工作区完成看证据、定结论、关工单、调账或赔付抵扣。

## 下一步建议

- 把调账/赔付记录加入账单争议报表和利润报表的独立口径。
- 在客户账单页显示“来源工单/原账单/调账原因”。
- 增加调账金额超过阈值时的二次审批。
