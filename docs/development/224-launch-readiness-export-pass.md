# 224 上线体检导出能力

## 本轮目标

- 让运营后台上线体检不仅能在页面查看，也能导出给老板、运营和仓库负责人复盘。
- 保持中文优先，避免 Excel/CSV 下载后出现英文表头或乱码。

## 已完成

- `/api/ops/launch-readiness?format=csv` 支持导出上线体检清单。
- CSV 包含生成时间、环境、总体状态、上线评分、检查项、状态、负责人、详情和关键业务指标。
- 运营后台上线体检卡片新增「导出体检表」按钮。
- CSV 使用 UTF-8 BOM 和中文文件名，方便 Excel 直接打开。

## 验证

- `npm run lint`：通过。
- `npm run build`：通过。

## 下一步

- 继续把生产健康检查、生产集成配置、上线体检和系统告警合并成更完整的上线复核包。
- 补齐更多导出文件的中文说明和老板视角汇总字段。
