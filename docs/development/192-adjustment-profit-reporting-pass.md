# 192 调账和赔付报表口径

## 本轮目标

让财务复核生成的费用调账、赔付抵扣不只存在于账单记录里，也能进入费用事件台账和利润/成本报表。

## 已完成

- 费用事件台账新增调账/赔付类型、来源工单、来源账单字段。
- 费用事件台账关键词搜索会覆盖调账类型、来源工单和来源账单。
- 利润/成本报表新增“费用调账”和“赔付抵扣”两列。
- 调账/赔付金额继续计入账单收入和毛利，同时独立展示，便于财务解释毛利变化。

## 对标马帮价值

- 财务可以从费用事件明细追溯每一笔调账/赔付的来源。
- 老板看利润报表时能区分正常收入、调账抵扣和赔付抵扣。
- 为后续按客户、员工、原因统计争议处理成本打基础。

## 下一步建议

- 在员工绩效报表里增加财务复核处理量、调账金额和赔付金额。
- 在客户账单详情页展示来源工单和原账单。
- 对大额调账接入审批规则。
