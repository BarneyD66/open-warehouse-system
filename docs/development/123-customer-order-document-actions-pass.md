# 123 客户订单级资料下载入口

## 背景

客户侧已经可以通过下载中心导出出库、面单、签收证明和异常资料，但日常操作里客户往往是先看到某一票出库/物流记录，再希望直接下载该票资料。为了减少跳转和查找成本，本次把高频资料入口下沉到具体订单卡片。

## 本次完成

- `/api/downloads` 新增可选 `orderId` 参数，出库明细、出库复核状态、面单列表、签收证明、物流异常与赔付、异常中心导出可按单过滤。
- 客户出库页的每条出库记录新增：
  - 出库明细下载
  - 复核状态下载
  - 面单查看/下载
  - 签收证明查看/下载
- 客户业务进度页的出库物流记录新增：
  - 出库明细下载
  - 面单查看/下载
  - 签收证明查看/下载
- 面单未生成、签收证明未回传时显示明确的不可用状态，避免客户误点。

## 客户体验变化

客户不需要先下载全量 CSV 再找链接，可以在具体出库单旁边直接查看和下载资料。运营和仓库侧原有权限控制不变，客户只能访问自己客户编号下的订单资料。
