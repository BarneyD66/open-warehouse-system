# 177 上线守门板

## 本轮目标

把上线体检、生产集成、系统健康、系统告警这些分散信息合并成一个老板和产品经理能直接看的上线责任清单。

## 已完成

- 新增 `OpsLaunchGuardPanel`。
- 在运营后台首页接入“上线守门板”。
- 汇总上线体检、生产集成配置、生产健康检查、系统告警。
- 自动区分“必须处理”和“需要关注”。
- 按产品、前端、后端、运营、运维、仓库、财务分派责任。
- 每个待办项展示来源、负责人、问题说明、下一步动作和处理入口。
- 汇总最小上线评分，避免单个评分好看但另一个模块仍有阻塞。

## 业务价值

- 发版前不用在多个面板里找问题，首页就能看到当前是否适合开放给真实客户。
- 老板可以直接看阻塞项数量和负责人分布。
- 产品经理可以按优先级推进环境变量、真实 API、文件安全、员工权限、备份恢复、系统告警等上线硬条件。

## 验证

- `npm run lint`
- `npm run build`
