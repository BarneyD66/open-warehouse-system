# 155 - 运营客户自助待办监控

## 背景

客户工作台已经可以把资料补充、账单确认、物流异常、退货处理和工单沟通整理成自助待办，但运营后台还缺少一个集中视图，员工需要分别进入多个模块才能判断哪些客户已经超时、哪些客户需要立即催办。

## 本次开发

- 新增 `customerSelfServiceOpsReport`，按客户聚合自助待办、SLA、紧急程度、可下载资料、账单、退货、异常和工单数量。
- 新增运营导出接口 `/api/ops/reports/customer-self-service`，支持汇总 CSV 和 `?detail=1` 明细 CSV，导出内容保持中文表头。
- 新增运营后台组件 `OpsCustomerSelfServicePanel`，在总览页展示客户总数、活跃客户、高风险客户、超时客户、紧急事项、即将超时和可下载资料。
- 新增 `OpsCustomerSelfServiceReminderButton`，运营可在该面板中直接生成到期提醒，把客户自助待办同步进入站内信/外部投递队列。
- 将“客户自助待办”接入报表中心模块、保存视图下拉框、保存视图导出和定时报表下载 URL，后续可以像库存、费用、SLA 报表一样统一管理。
- 顺手补齐“文件安全台账”的报表中心接入：保存视图、定时报表、风险计算和 documents-security 导出入口都纳入统一报表目录。
- 在运营总览中接入该面板，位于 SLA 报表之后、报表中心之前，便于每日先看超时和高风险客户。

## 验收口径

- 运营人员可以在总览页直接看到需要优先处理的客户。
- 老板可以通过汇总导出查看风险客户清单，通过明细导出分配客服逐条跟进。
- 有超时或即将超时事项时，运营可以在同一面板直接触发提醒生成，不需要切到其他配置页。
- CSV 表头、枚举和提示文案均为中文，避免客户/员工下载后出现英文模板。
