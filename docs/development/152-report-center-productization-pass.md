# 152 报表中心产品化

## 本轮目标

对标马帮“查得快、能保存视图、能定时发送、能快速定位异常”的报表体验，把当前分散的导出能力收敛成运营首页可见的报表中心。

## 已完成

- 新增报表中心统计服务，统一计算保存视图、定时报表、最近导出和高风险报表模块。
- 新增 `/api/ops/reports/center`，支持 JSON 查询和 `format=csv` 导出“报表中心总览”。
- 运营首页新增“报表中心”面板，展示保存视图、启用/暂停计划、投递失败、近期导出和高风险模块。
- 报表中心按库存、库位、批次、出库复核、拣货波次、承运商面单、平台同步、费用、账龄、收款核销、利润、退货、异常、扫码、SLA、客户信用、数据质量、员工绩效、自动化、通知投递等模块归类。
- 高风险模块根据当前库存、出库、面单、账单、退货、通知投递和自动化运行数据动态判断，运营可直接点击导出明细。
- 报表中心导出写入审计日志，便于后续追溯谁导出了总览。

## 使用价值

- 老板和运营无需记住每个报表入口，首页即可看到哪些报表最该看。
- 保存视图和定时报表有了集中状态，能快速发现投递失败或未配置问题。
- 报表中心总览可作为每日运营晨会、异常复盘和发版前检查的统一清单。
