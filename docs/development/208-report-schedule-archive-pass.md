# 208 定时报表归档状态

## 本轮目标

补齐定时报表的生命周期管理，避免无效计划只能暂停、不能清理，长期堆积在运营后台。

## 已完成

- 定时报表状态新增 `archived` 归档。
- 报表中心摘要增加归档统计，并将指标展示为“暂停/归档”。
- 报表中心默认隐藏已归档计划。
- 定时报表行内管理新增“归档”按钮。
- 定时任务执行仍只处理启用状态，归档计划不会被自动执行。
- 马帮对标模块里的定时报表小列表同步隐藏归档计划。
- 旧入口状态下拉支持创建/保存为归档状态。

## 价值

运营人员可以把废弃或过期的定时报表从日常列表中清理出去，同时保留配置和历史状态，不会误触发发送任务。

## 后续建议

- 增加“查看归档计划”切换。
- 增加定时报表执行历史详情。
- 给定时报表变更写入独立审计日志。
