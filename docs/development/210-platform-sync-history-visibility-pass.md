# 210 平台同步记录可视化

## 本轮目标

继续补齐对标马帮后的平台订单 API 同步闭环，让运营能在一个看板里看到店铺连接、单店铺同步动作和每次同步结果。

## 已完成

- 在平台同步健康看板中为每个 API 店铺连接展示最近一次同步结果。
- 新增“最近同步记录”区域，展示平台、店铺、客户、同步模式、执行时间、拉取行数、可建单数、跳过行数、异常数、取消订单数。
- 同步失败时直接展示失败原因。
- 同步成功且生成导入预检草稿时，提供“查看导入预检草稿”入口。
- 保留平台同步任务导出入口，便于运营导出报表追踪。

## 产品价值

- 运营可以判断是连接异常、平台没有新订单、字段校验失败，还是已经生成待确认导入草稿。
- 后续接入 Amazon、TikTok Shop、Shopify、eBay 真实 API 后，接口返回异常可以在业务看板里直接追踪。
- 平台订单同步从“后台任务”更接近可日常使用的运营闭环。

## 下一步建议

- 给平台连接补凭证健康探测按钮，明确显示 token、endpoint、权限范围是否可用。
- 把平台同步失败自动转成系统告警或待办，避免运营遗漏。
