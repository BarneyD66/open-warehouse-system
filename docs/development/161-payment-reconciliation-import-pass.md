# 161 银行流水导入与账单自动核销

## 背景

对标马帮类仓储物流系统的财务实账能力，现有系统已经支持账单生成、客户提交付款、运营人工复核、月结锁定和承运商账单核对。本轮补齐“收款流水导入后自动匹配账单”的财务闭环。

## 已完成

- 新增银行流水 CSV 模板下载，字段包含银行流水号、付款参考号、账单编号、月结单号、客户编号、到账金额、币种、到账日期、付款方和备注。
- 新增银行流水导入批次与明细记录，保存自动核销行数、待复核行数、月结核销行数、流水总额和已核销金额。
- 新增保守匹配规则：
  - 账单编号唯一命中且金额一致时，自动核销单笔账单。
  - 月结单号命中且客户当月未付账单合计金额一致时，自动核销月结账单。
  - 付款参考号或银行流水号命中已有付款参考时，按单笔或月结合计金额自动核销。
  - 客户编号加金额唯一命中时，自动核销单笔账单。
  - 多候选、争议账单、非 GBP 币种、金额不一致、找不到账单时只记录跳过原因，不自动改账。
- 新增运营后台账单模块“银行流水导入与自动核销”面板，支持上传 CSV、查看最近批次、下载核销明细。
- 新增审计动作 `billing_payment_import`，记录导入批次和自动核销摘要。

## 验收点

- 财务人员可下载模板并上传真实银行流水。
- 自动核销只处理金额一致且唯一可确认的记录。
- 待人工复核的行能在明细里看到明确原因。
- 老账单数据兼容新增字段，不影响已有费用规则和付款复核流程。
