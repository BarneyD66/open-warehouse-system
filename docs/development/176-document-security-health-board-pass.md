# 176 文件安全与对象存储巡检看板

## 本轮目标

对标马帮类系统的资料归档、附件安全和生产级文件基础设施，把已有的文件上传、病毒扫描、预览、下载、人工放行/拦截能力集中到运营后台，形成员工可日常巡检的文件安全入口。

## 已完成

- 新增 `OpsDocumentSecurityHealthPanel`。
- 在运营后台账单/资料区域接入“文件安全与对象存储巡检”。
- 增加文件总数、扫描通过率、对象存储覆盖率、待扫描、已拦截、本地/数据库存储统计。
- 增加待处理文件队列，覆盖待扫描、已拦截、非对象存储、大文件、不可预览文件。
- 增加客户资料风险分布，便于老板和运营快速看到哪个客户资料风险更集中。
- 复用现有文件安全动作，支持单文件复扫、放行、拦截。
- 增加批量复扫待扫描文件入口，每次最多处理 20 个，避免误触发大量请求。
- 增加文件安全台账和待处理台账导出入口。

## 业务价值

- 员工每天打开运营后台即可看到文件侧是否存在安全风险。
- 老板可以从统计和客户风险分布判断资料安全、对象存储迁移和客户附件处理是否健康。
- 后续接入 S3、Vercel Blob、ClamAV 或第三方病毒扫描时，前台巡检口径不需要重做。
