# 217 文件拒绝上传运营可视化

## 本轮目标

继续补齐对象存储与文件安全能力，让文件安全看板不仅能看已入库文件风险，也能看到最近被安全策略拒绝的上传尝试。

## 已完成

- 文件安全看板接入审计日志。
- 新增“最近拒绝上传”区域。
- 展示最近 5 条被拒绝上传：
  - 文件名；
  - 客户编号；
  - 关联业务类型和单号；
  - 拒绝时间；
  - 拒绝原因。
- 复用 `document_upload_rejected` 审计动作，不新增重复存储。

## 产品价值

- 运营在文件安全看板内即可看到危险附件、异常文件、病毒扫描阻断等上传拒绝事件。
- 文件安全从“只看已保存文件”升级为“上传前拦截和上传后复核都能看见”。

## 下一步建议

- 增加按客户、上传人、拒绝原因筛选。
- 对连续被拒绝的客户或账号自动生成工单或消息提醒。
