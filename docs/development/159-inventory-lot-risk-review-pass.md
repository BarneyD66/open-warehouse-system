# 159 库存批次风险自动巡检

## 背景

系统已经具备批次号、效期、序列号、冻结、预留、释放、消耗和批次风险报表。本轮补齐更接近日常 WMS 的自动巡检闭环：不仅能看到临期/过期/冻结风险，还能把风险刷新成状态和运营待办。

## 本轮完成

- 新增库存批次风险巡检业务能力：
  - 扫描库存批次。
  - 识别已过期、临期、冻结批次、冻结序列号、仅剩预留库存。
  - 已过期但状态尚未刷新的批次，自动通过批次更新流程刷新为过期状态。
  - 为风险批次生成“库存批次风险”运营工单。
  - 同一批次已有未关闭风险工单时不重复创建。
- 新增 API：
  - `GET/POST /api/ops/inventory-lots/risk-review`
  - 支持 `admin`、`ops`、`warehouse` 员工调用。
  - 支持 `INVENTORY_LOT_RISK_REVIEW_SECRET` 或 `CRON_SECRET` 定时调用。
- 接入自动化调度：
  - `/api/ops/automation/run-due` 增加 `inventory_lot_risk_review` 子任务。
  - `/api/ops/automation/task-actions` 支持失败后重试。
- 运营页面增强：
  - 库存批次面板新增 `巡检批次风险` 按钮。
  - 执行后展示扫描批次数、复核数、标记过期数、工单数和失败数。
- 审计日志增强：
  - 新增 `inventory_lot_risk_review_due` 审计动作。
  - 审计列表和导出接口增加中文标签。

## 价值

把“批次/效期风险报表”升级为“状态刷新 + 运营待办 + 审计留痕”的闭环，减少过期批次继续混入仓库日常拣货、上架和客户沟通流程的风险。
