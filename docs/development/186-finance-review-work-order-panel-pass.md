# 186 财务待复核工单面板

## 本轮目标

把客户提交的账单争议、物流费用差异复核工单接入财务视角，避免只停留在客服工单队列。

## 已完成

- 账单争议复核队列新增“待复核工单”统计。
- 财务面板新增“待财务复核工单”区域。
- 展示客户、工单编号、分类、关联单号、客户描述、内部提示和风险标签。
- 支持直接进入物流证据包或账单证据入口。
- 运营页已把客户自助工单数据传入账单争议组件。

## 对标马帮价值

- 财务不需要在客服队列里筛费用问题，费用复核事项能在账单工作区集中处理。
- 客户提交费用异议后，后台可从财务视角看到“账单争议 + 物流证据 + 客户说明”的完整上下文。
- 为后续复核结论、账单调整审批和争议关闭动作打基础。

## 下一步建议

- 增加财务复核结论字段：同意调整、维持原账单、需客户补充证据。
- 将复核结论回写到工单消息和账单 reviewNote。
- 在账单列表增加“有待复核工单”筛选。
