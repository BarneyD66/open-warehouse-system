# Pass 172 - SLA 升级看板

## 背景

系统已有运营待办中心、客户待办、SLA 报表、通知订阅和外部通知投递能力。但对老板和运营负责人来说，普通待办列表仍然不够突出“今天必须优先处理的风险”。因此本轮补一个总览级 SLA 升级看板。

## 本次新增

- 新增 `OpsSlaEscalationPanel`。
- 在运营后台总览中，将 SLA 升级看板放在运营待办中心之前。
- 自动筛选以下待办：
  - 已超时。
  - 即将超时。
  - 高优先级。
- 展示核心信息：
  - 高优先级数量。
  - 已超时数量。
  - 即将超时数量。
  - 来源模块、客户编号、关联单号、创建时间、通知渠道和处理入口。
- 支持直接点击“去处理”进入对应业务页面。

## 产品价值

- 老板视角：进入运营后台即可看到当前最紧急风险。
- 运营视角：不用在全部待办中人工筛选超时项。
- 与现有通知体系复用：不重复生成任务，只重组已有通知数据。
