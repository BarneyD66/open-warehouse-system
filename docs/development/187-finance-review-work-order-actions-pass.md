# 187 财务复核工单处理动作

## 本轮目标

让财务在账单争议面板内直接处理费用复核工单，而不是只能回到客服工单队列。

## 已完成

- 运营 API 新增 `review_finance_work_order` 动作，并归属 billing 权限模块。
- 财务可将费用复核工单标记为接单复核、需客户补充、复核完成。
- “需客户补充”和“复核完成”会自动写入客户可见工单消息。
- 财务面板支持填写复核说明，并在操作后刷新页面。
- 复核动作会同步更新工单内部提示，便于后续追溯。

## 对标马帮价值

- 费用争议从“看见问题”推进到“可以处理问题”。
- 财务处理过程可沉淀在工单消息和内部备注里，客户与员工都能看到状态变化。
- 为后续账单调整审批、账单争议关闭和付款核销联动留出接口。

## 下一步建议

- 将复核结论进一步写回具体账单或出库单。
- 增加“同意调整/维持账单/赔付处理”结构化结论。
- 把费用复核处理记录纳入账单争议报表和员工绩效统计。
