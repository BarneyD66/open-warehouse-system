# 149 库位规则与出库波次效率

## 本轮目标

继续对标马帮的日常仓库作业能力，把库位规则、批量组波次、拣货效率报表和操作审计串成一条可运营的链路。

## 已完成

- 库位维护接口完成中文化，新增限流与操作审计。
- 库位 CSV 批量导入会记录成功数、异常数和审计日志。
- 库位管理面板完成中文化，展示容量、剩余件数、利用率、混放规则和风险标签。
- 出库批量处理接口完成中文化，批量状态变更新增审计日志。
- 批量生成拣货波次继续支持按作业模式、承运商、渠道、截单时间、库区、SKU 热度或合并波次分组。
- 出库批量面板完成中文化，运营可直接选择未发货订单、生成波次、打印批量拣货单、导出波次报表。
- 波次执行效率报表完成中文化，覆盖拣货/分拣/复核缺口、称重缺口、异常数量、停滞小时和下一步处理建议。
- 操作日志面板补充库位维护、出库状态批量更新等新动作映射。

## 对标马帮后的价值

- 仓库能按库区、承运商、截单时间和 SKU 热度组织出库波次，不再只靠人工经验排单。
- 老板和运营可以通过波次报表看到每个波次卡在哪一步：拣货、分拣、复核、称重、异常或交接。
- 库位容量、混放、空库位、满仓风险可直接在仓库面板上查看，减少上架和移库返工。

## 后续可继续

- 继续细化二次分拣、称重校验、异常截单和拣货员绩效。
- 把库位容量从件数进一步扩展到体积、重量和商品尺寸规则。
- 增加移动端扫码作业的波次进度看板。
