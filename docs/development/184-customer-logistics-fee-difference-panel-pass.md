# Pass 184 - 客户物流费用差异提示

## 背景

Pass 183 已经提供“物流证据包”下载，但客户进入工作台时仍需要直接看到哪些出库单存在运费差异，以及下一步应该下载证据、查看账单还是提交工单。

## 本轮完成

- 新增客户工作台“物流费用差异”面板。
  - 展示待复核出库单数量。
  - 展示合计运费差异。
  - 展示最多 5 条差异最大的出库单。
  - 字段包含出库单号、承运商/渠道、追踪号、预估运费、实际运费、差异金额、运营说明、更新时间。

- 增加三个客户动作入口。
  - 下载物流证据包。
  - 查看账单页。
  - 提交已预填的“物流费用差异复核”工单。

- 处理规则。
  - 仅展示预估运费和实际运费均存在，且差异绝对值大于等于 £1 的出库单。
  - 差异大于等于 £5 标记为严重差异。

## 验证

- `npm run lint`
- `npm run build`

两项均通过。

## 后续优先级

1. 将客户提交的费用复核工单与账单争议记录自动关联。
2. 在账单页按出库单展示物流费用差异明细。
3. 将承运商账单导入后的实际费用变动自动通知客户。
