# 124 备份与恢复治理

## 背景

正式上线前，仓储/物流系统需要具备可审计的备份导出、恢复前预检和恢复操作保护。原系统已有备份下载 API 与恢复 API，但运营后台缺少清晰入口，备份导出也没有进入审计日志。

## 本次完成

- 系统备份导出 `/api/ops/system/backup` 写入审计日志，记录导出人、导出时间和核心数据规模。
- 系统备份导出增加限频保护，10 分钟最多 5 次，降低管理员会话被滥用后的数据泄露风险。
- 新增运营后台“备份与恢复治理”面板：
  - 导出系统备份。
  - 选择或粘贴备份 JSON。
  - 执行恢复前 dry-run 预检。
  - 展示备份版本、导出人、导出时间和数据量摘要。
  - 必须填写确认短语 `RESTORE_WAREHOUSE_SYSTEM` 才能执行恢复。
  - 展示最近备份/恢复审计记录。
- 审计日志导出和后台审计面板补充“系统备份导出”中文动作名称。

## 生产价值

- 老板/管理员可以在发版前人工导出快照。
- 恢复前能先确认备份结构和覆盖范围。
- 备份与恢复都能在审计日志中追溯到操作人。
- 降低误恢复风险，符合生产运维和安全能力要求。
