# 物流附加费与渠道黑名单

## 本次补强

- 运营后台配置的物流渠道规则现在会参与承运商匹配、运费试算和面单生成。
- 支持偏远地区附加费：当规则包含“偏远”或 `remote`，且收件邮编属于英国偏远前缀时，自动加收附加费。
- 支持燃油附加费：当规则包含“燃油”或 `fuel`，可按百分比计算；没有写百分比时默认按 6%。
- 支持超尺寸/多包裹附加费：当规则包含“超尺寸”或 `oversize`，且重量超过 10kg 或包裹数大于 1 时自动加收。
- 支持渠道黑名单：规则写 `黑名单: CUST-xxx`、`渠道黑名单=DPD` 或 `blacklist: keyword`，命中客户、地址、渠道或承运商关键词时会拦截。
- 命中黑名单时，试算会提示原因；生成面单会被阻止，并把出库单面单状态标记为失败。

## 配置示例

```text
偏远附加费: 2.8
燃油费: 6%
超尺寸费: 2.5
渠道黑名单: CUST-202605-3054
blacklist: DPD
```

## 对标价值

马帮类系统的物流和财务闭环不仅要能生成面单，还要把偏远费、燃油费、超尺寸费、渠道限制和黑名单纳入规则。这样运营批量匹配渠道时，系统能提前暴露成本和限制，减少发错渠道、账单差异和后续赔付。
