# 出库波次与拣货效率报表增强

## 本轮目标

出库波次已经支持按作业模式、承运商、渠道、截单时间、库区和 SKU 热度自动组波，但日常管理还需要更清晰地判断每个波次是否卡住、差多少数量、下一步该谁处理。

## 已完成

- 重写并增强 `/api/ops/reports/pick-waves`，导出文件改为干净中文。
- 报表新增拣货缺口、分拣缺口、复核缺口、拣货完成率、分拣完成率、复核完成率。
- 报表新增待称重订单数、未处理异常、严重异常、最新扫码时间、停滞小时和下一步处理建议。
- 波次状态新增“有异常、疑似卡住、待称重、复核中、分拣中、拣货中、待交接、待开始、已完成”等更贴近日常管理的分类。
- 支持 `customerCode`、`status`、`keyword` 筛选，并支持 `format=json` 供后续看板复用。
- 已接入保存视图和定时报表，可用于每天推送波次执行效率。
- 运营后台报表快捷区新增“导出波次执行效率”入口。

## 产品价值

仓库主管不再只看“有没有波次”，而是可以直接看到哪个波次卡住、卡在拣货/分拣/复核/称重/异常哪一步，以及下一步应该处理什么。
