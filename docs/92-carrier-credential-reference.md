# 承运商凭证引用

本次补齐真实承运商 API 上线前的凭证引用管理。

## 已完成

- `LogisticsChannelConfig` 新增 `credentialRef`。
- 运营后台物流渠道配置表单新增“凭证引用”字段。
- 物流渠道列表展示凭证引用是否已配置。
- 渠道健康检查新增“缺少承运商凭证引用”风险。
- 上线体检的承运商闭环检查纳入凭证引用。
- 数据质量巡检报表纳入凭证引用检查。
- 物流渠道导出新增“凭证引用”列。

## 设计原则

页面不直接保存或展示真实 API Key，只保存环境变量或密钥系统中的引用名，例如 `ROYAL_MAIL_API_KEY`，后续接真实承运商 API 时由后端通过该引用读取密钥。
