# 员工白名单与权限审计页

本次补齐运营后台的员工准入可视化能力，避免员工白名单只存在于环境变量和登录逻辑里。

## 已完成

- `staffAuth` 新增安全白名单视图，只展示用户名、显示名、角色、来源和风险，不向前端暴露密码。
- 上线体检的“员工白名单”检查项增加白名单数量、来源和风险说明。
- 运营后台“审计”模块新增员工白名单准入状态、角色权限矩阵和审批规则中心。
- 审计页保留操作日志，形成“谁能登录、能做什么、哪些动作要审批、实际做过什么”的完整追溯链路。

## 上线判断

生产后台建议配置 `STAFF_WHITELIST_JSON`，并关闭 `ALLOW_DEMO_STAFF_LOGIN`。如果生产仍使用演示白名单，系统会在上线体检和审计页显示风险。
