# 表单提交 API 与内部队列

## 产品经理目标

网站不能只让客户“看起来提交成功”。当前阶段先做最小业务闭环：

客户提交合作询盘或入库预报 -> API 生成编号 -> 信息写入本地 JSON -> 内部运营页可查看。

后续再替换为正式数据库、客服通知和权限系统。

## 已完成

- `/api/inquiries`：合作询盘提交 API
- `/api/inbounds`：入库预报提交 API
- `.local-data/submissions.json`：本地提交记录
- `/ops`：内部运营查看页

## 合作询盘闭环

表单提交字段：

- 公司/店铺名称
- 联系人
- 手机/微信
- 邮箱
- 销售平台
- 预计月单量
- 主要服务需求
- 货物所在地
- 需求描述

提交结果：

- 服务端生成 `INQ-YYYYMM-XXXX`
- 状态为 `new`
- 内部 `/ops` 页面显示为“新询盘”

## 入库预报闭环

表单提交字段：

- 客户/店铺名称
- 联系人
- 手机/微信
- 平台
- 预计到仓日期
- 运输方式
- 承运商/追踪号
- 箱数/托数
- SKU 数量
- 主要品名/SKU
- 需要的服务
- 特殊属性
- 附件文件名

提交结果：

- 服务端生成 `ASN-UK-YYYYMM-XXXX`
- 状态为 `pending_review`
- 内部 `/ops` 页面显示为“待审核”

## 验证结果
