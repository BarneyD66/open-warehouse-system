# 105 通知投递失败纳入系统告警

本轮把消息中心的外部通知投递失败接入系统告警中心，补齐生产运维中“消息没有送达也要被看到”的闭环。

## 已完成

- `SystemAlert.source` 增加 `notification`。
- 系统告警生成逻辑新增通知投递规则：
  - `failed` 投递失败会进入告警。
  - `blocked` 配置阻断会进入告警。
  - 同一条通知失败尝试达到 3 次及以上时标为严重。
- 告警详情包含：
  - 接收对象：客户或员工。
  - 客户编号。
  - 来源模块和来源单号。
  - 尝试次数。
  - 失败原因。
  - 建议重试时间。
- 渠道名称做中文归一化，避免邮件、短信、微信在告警里显示不清楚。

## 业务价值

- 客户或员工没有收到关键通知时，运营能在系统告警中心看到。
- 老板可以在健康检查和告警中心判断通知闭环是否真的可靠。
- 通知台账、批量重试、自动重试和系统告警形成完整运维闭环。
