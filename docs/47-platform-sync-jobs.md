# 47. 平台同步任务记录

## 已完成

- 平台连接新增同步任务记录，记录平台、店铺、客户编号、同步模式、执行人、拉取行数、可创建订单、异常数和失败原因。
- 运营后台「平台订单导入和字段映射」新增：
  - 平台连接列表。
  - 立即同步按钮。
  - 最近同步记录。
  - 同步记录 CSV 导出。
- `api_sandbox` 模式可以生成一条平台订单同步预检草稿，运营可继续查看异常报告或确认创建出库单。
- `api_live` 模式在未配置凭证引用时会明确失败，并把失败原因写入同步记录和平台连接备注。
- `manual_csv` 模式会提示继续使用模板导入，避免误以为已经接入平台 API。

## 产品价值

- 对标马帮的平台同步工作台，运营能看清楚「有没有同步、同步了多少、失败在哪里」。
- 正式 API 未接入前，也能用沙箱同步跑通字段映射、预检、导入批次和异常处理链路。
- 后续接 Amazon、TikTok Shop、Shopify、eBay 的真实 API 时，可以沿用同步任务记录和导入草稿流程。
