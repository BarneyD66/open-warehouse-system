# 员工准入与权限审计报表

本次新增员工准入与权限审计导出能力，用于上线前和日常运营复核。

## 已完成

- 新增 `/api/ops/reports/staff-access`。
- 仅允许具备“权限”模块访问权的员工导出。
- 报表包含三类内容：
  - 员工白名单：员工、账号、角色、来源、准入风险。
  - 角色权限：角色、可访问模块、敏感操作、是否二次确认。
  - 审批规则：触发场景、状态、审批角色、SLA、原因/附件/阈值要求。
- 导出动作写入操作审计日志。
- 运营后台“审计”模块的员工白名单卡片新增“导出员工准入”入口。

## 产品价值

老板和管理员可以直接下载当前员工可登录范围与关键操作权限，避免生产环境只靠口头确认或环境变量截图来管理权限。
