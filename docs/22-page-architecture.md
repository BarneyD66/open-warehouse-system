# 页面分类与入口治理

## 产品结论

当前网站需要明确分成三类页面，避免客户官网、客户工作台和内部后台混在一起。

## 1. 客户看到的公开官网

目标用户：还没合作或还没登录的中国跨境卖家。

目标：建立信任，说明服务包含什么、费用怎么产生、入仓怎么操作、仓库在哪里。

页面：

| 页面 | 用途 |
| --- | --- |
| `/` | 官网首页，解释定位、服务范围和下一步入口 |
| `/services` | 服务项目说明 |
| `/workflow` | 操作流程说明 |
| `/pricing` | 价格计费和费用预估 |
| `/help` | 帮助中心 |
| `/contact` | 联系方式和谢菲尔德仓库信息 |

## 2. 客户登录后的 Dashboard 与自助操作

目标用户：已提交询盘、准备入仓或已经合作的客户。

目标：让客户处理自己的待办，减少反复问客服。

页面：

| 页面 | 用途 |
| --- | --- |
| `/login` | 客户登录入口，当前支持 `test / test` 演示账号 |
| `/portal` | 登录后的客户 Dashboard，看待办、报价、入库、异常和费用 |
| `/inquiry` | 提交合作询盘 |
| `/inbound` | 创建入库预报 |
| `/tracking` | 不登录也可查询盘或入库进度 |
| `/supplement` | 补交追踪号、箱唛、装箱单等资料 |

## 3. 海外仓管理后台

目标用户：我们内部客服、运营、仓库和财务。

目标：处理客户提交过来的业务，不面向客户展示。

页面：

| 页面 | 用途 |
| --- | --- |
| `/ops` | 内部运营后台，处理询盘报价、入库预报、缺资料和缺追踪号队列 |
| 后续 WMS | 收货、上架、拣货、打包、退货质检、FBA 作业和费用计费 |

## 导航原则

- 公开官网导航只放客户能理解的内容：服务、流程、价格、帮助、联系我们。
- 客户操作入口单独成组：登录、询盘、入库、查进度、补资料。
- 内部后台单独成组，不和客户门户混用。
- `/portal` 只作为登录后 Dashboard，不再承担公开营销介绍。
- `/ops` 明确是内部后台，不让客户误以为这是客户工作台。
