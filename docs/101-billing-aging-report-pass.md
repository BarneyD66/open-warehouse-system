# 费用与财务实账：应收账龄报表

## 本轮目标

账单、月结、自动费用、付款核销和争议审批已有基础，但真实运营还需要一个财务每天能看的应收账龄报表，用来判断哪些客户即将到期、逾期、付款待复核或存在争议。

## 已完成

- 新增 `/api/ops/reports/billing-aging` 应收账龄报表。
- 报表按客户汇总未结笔数、未结金额、7 天内到期金额、逾期总额、逾期 0-7 天、8-30 天、31-60 天、60 天以上金额。
- 报表新增付款待复核金额、争议金额、已锁定月结单数、最近到期日、风险等级和下一步处理建议。
- 风险等级分为“正常、关注、高风险”，高风险优先覆盖长期逾期和账单争议。
- 支持 `customerCode`、`risk` 筛选，并支持 `format=json` 给后续财务看板复用。
- 已接入保存视图和定时报表，可每日推送财务催收清单。
- 运营后台报表快捷区新增“导出应收账龄”入口。

## 产品价值

财务不再只看账单明细，而是可以按客户直接判断收款风险、催收优先级、付款凭证待复核和争议账单，支撑真实月结运营。
