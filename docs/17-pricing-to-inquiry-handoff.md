# 费用预估到询价交接闭环

## 目标

中国跨境卖家在官网费用预估器里输入平台、月单量、入库量、库存体积、退货和 FBA 补仓量后，可以直接点击“带着预估去询价”。询价页自动带入业务量和费用预估，运营后台可以看到完整上下文，减少客服二次追问。

## 产品要求

- 客户侧不需要重复填写平台、月单量、主要服务需求。
- 预估结果以说明卡片展示，避免客户误以为是正式报价。
- 提交后的询盘必须保存费用预估文本，便于销售和客服判断客户体量。
- 运营后台需要在新询盘卡片里突出费用预估，优先跟进高意向线索。
- 运营后台必须标注费用预估线索，并提醒客服该结果不是正式报价。
- 进度查询接口应允许客户或客服通过费用预估相关关键词检索记录。

## 字段流转

| 来源 | 字段 | 去向 |
| --- | --- | --- |
| `/pricing` | `platform` | `/inquiry` 平台默认值 |
| `/pricing` | `service` | `/inquiry` 服务默认值 |
| `/pricing` | `monthlyOrders` | `/inquiry` 月单量区间 |
| `/pricing` | `totalGbp` / `totalCny` / `perOrderGbp` | `quoteEstimate` 文本 |
| `/inquiry` | `quoteEstimate` | `/api/inquiries` 本地线索池 |
| 本地线索池 | `quoteEstimate` | `/ops` 运营后台、`/api/tracking` 查询摘要 |

## 验收标准

- 从费用页点击 CTA 后进入 `/inquiry?source=pricing-estimator...`。
- 询价页出现“已带入费用预估”卡片。
- 平台、月单量和服务类型自动选中。
- 询价提交成功后，本地线索包含 `quoteEstimate`。
- `/ops` 对应询盘显示“费用预估线索”和“优先跟进：客户已完成费用预估”。
- `/api/tracking` 的询盘摘要显示“已带费用预估”。

## 后续可扩展

- 把 `quoteEstimate` 拆成结构化报价快照，支持正式报价单和价格版本管理。
- 给后台增加“按预估金额排序”和“高意向线索”标签。
- 接入 CRM 通知，把带预估的询盘推送到销售微信或企业微信。
