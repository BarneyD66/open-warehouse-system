# 102 通知投递台账报表补齐

本轮把消息中心的外部通知投递记录产品化为运营可用报表，继续补齐对标马帮后的“消息中心、SLA 提醒、异常升级”能力。

## 已完成

- 新增 `/api/ops/reports/notification-deliveries`：
  - 支持导出 CSV 和 `format=json`。
  - 支持按状态、渠道、接收对象、客户编号、关键词筛选。
  - 字段包含投递编号、通知编号、接收对象、客户编号、渠道、来源模块、来源单号、标题、状态、尝试次数、最后错误、建议重试时间、送达时间、创建时间、更新时间、下一步处理。
- 将通知投递报表接入保存视图与定时报表：
  - `notification_deliveries` 可作为保存视图模块。
  - 定时报表可生成通知投递台账下载链接。
- 在运营后台报表快捷导出区增加“导出通知投递台账”。
- 新报表输出使用中文字段和中文状态，避免下载后出现英文表头。

## 业务价值

- 运营可以快速判断邮件、短信、微信通知是否真正投递。
- 失败通知可以看到失败原因、重试建议和下一步处理。
- 对配置阻断的通知可以定位到缺少 webhook 配置，便于上线前检查。
