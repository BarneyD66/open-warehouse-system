# 物流匹配规则与费用核对

## 对标马帮缺口

马帮物流模块里有物流授权、物流匹配规则、物流跟踪、物流费用和统计。我们此前已经完成了面单 MVP、运费试算和追踪回传，但还缺一个运营集中视图，用来处理：

- 哪些出库单还没匹配物流渠道。
- 哪些单有面单、追踪或轨迹风险。
- 哪些单预估运费和实际运费有差异。
- 如何把渠道匹配规则从单个订单操作提升为批量处理。

## 本轮完成

- 运营后台新增“物流规则与费用核对”面板。
- 新增物流规则推荐逻辑：按渠道文本、FBA/人工渠道、加急、经济件和估算重量推荐承运商服务。
- 新增一键匹配接口：`/api/ops/logistics/match`，可批量为待处理出库单写入推荐渠道和预估运费。
- 出库物流操作组件新增“实际运费”和“运费核对备注”。
- 出库单数据新增实际运费、核对时间、核对人和备注字段。
- 物流核对面板展示待匹配、物流风险、费用差异和有追踪号数量。

## 当前规则

- FBA、Amazon、客户自送或 manual 文本：推荐人工/客户渠道。
- next day、express、urgent、DPD 文本：推荐 DPD Next Day。
- economy、Evri 文本：推荐 Evri Standard。
- 估算重量大于 5kg：推荐 DPD Next Day。
- 轻小件默认 Royal Mail Tracked 48。

## 验证

- `npm run lint` 通过。
- `npm run build` 通过，构建清单包含 `/api/ops/logistics/match`。
- 本地运营后台 `/ops` 可渲染“物流规则与费用核对”和“一键匹配待处理”。
- 本地 `/api/ops/logistics/match` 员工登录后返回 200。
- 运费核对缺少实际运费时返回 400。
