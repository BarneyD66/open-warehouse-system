# 退货 RMA 标签打印

## 目标

退货包裹需要有可识别的 RMA 标签，仓库员工拿到包裹后可以直接扫码定位退货单，减少人工搜索和错绑。

## 已落地能力

- 运营后台退货列表新增“打印 RMA 标签”入口。
- RMA 标签打印页需要员工登录后访问。
- 标签包含 Code 128 条码、人眼可读 RMA 单号、客户编号、平台、原订单号、买家退货追踪号、预计到仓、库位、处理方式和 SKU 明细。
- 标签底部预留到仓签收、质检人和处理确认签名区。
- 扫码枪扫描 RMA 条码后，可以在仓库扫码台退货/RMA 模式下定位退货单。

## 使用路径

1. 运营进入后台退货 / RMA 列表。
2. 点击退货单下方的“打印 RMA 标签”。
3. 使用浏览器打印 A4 或 A6 标签。
4. 标签贴在退货包裹、退货篮或质检操作单上。
5. 仓库员工在扫码台选择“退货/RMA”，扫描标签条码推进到仓或质检。

## 后续可增强

- 客户提交退货预报后，也允许客户自行下载 RMA 标签。
- 按标签纸尺寸提供 A6、50x80、100x150 三种打印模板。
- 批量打印当天预计到仓的 RMA 标签。
