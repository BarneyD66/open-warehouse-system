# 78. 运营后台异常中心面板

## 本轮目标

异常中心不能只有导出，运营和老板进入后台后也要能直接看到跨模块异常队列。

## 已完成

- `/ops` 总览页新增“异常中心”面板。
- 汇总入库收货差异、入库状态异常、出库/物流异常、退货/RMA待确认、库存风险和账单逾期。
- 显示异常总数、严重异常数、模块、关联单号、客户编号、异常说明、下一步动作和发生时间。
- 面板提供“导出异常中心”按钮，连接 `/api/ops/reports/exceptions`。

## 价值

运营不用进入多个模块逐个找异常，老板也能在总览页第一时间看到风险队列。这个体验更接近马帮类系统的“异常优先处理”工作方式。
