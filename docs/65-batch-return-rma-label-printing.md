# 批量退货 RMA 标签打印

## 目标

仓库日常不是一单一单打印标签，而是按当天预计到仓、待质检或当前列表批量打印。批量 RMA 标签可以减少退货到仓前的准备时间。

## 已落地能力

- 运营后台退货 / RMA 列表顶部新增“批量打印 RMA 标签”。
- 默认取当前退货列表中前 50 张未结束退货单。
- 批量打印页每张退货单生成一张独立 RMA 标签。
- 打印时每张标签自动分页。
- 标签包含 Code 128 条码、客户、平台、原订单、退货追踪号、预计到仓和 SKU 明细。
- 批量标签可配合仓库扫码台退货/RMA 模式使用。

## 使用路径

1. 运营进入后台退货 / RMA 模块。
2. 点击“批量打印 RMA 标签”。
3. 浏览器打开批量打印页。
4. 点击打印，系统按每张 RMA 标签分页输出。
5. 仓库员工收到包裹后扫描标签推进到仓和质检。

## 后续可增强

- 支持按日期、客户、状态筛选后批量打印。
- 支持客户侧下载单张 RMA 标签。
- 支持导出 ZPL/热敏标签格式。
