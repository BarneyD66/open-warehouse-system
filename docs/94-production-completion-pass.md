# 生产级补齐推进记录

Date: 2026-06-18

## 本轮完成

### 1. 真实承运商 API 闭环

- 新增 `carrierGateway` 适配层。
- 出库生成面单时，会根据物流渠道配置判断 `manual`、`sandbox`、`live`。
- `manual/internal` 模式继续生成内部面单，保证现有流程可用。
- `sandbox/live` 模式要求配置凭证引用和接口地址，缺少配置会明确失败，不再伪装成真实买单成功。
- 新增承运商轨迹 webhook：`/api/webhooks/carriers/[provider]`。
- 承运商轨迹 webhook 安全增强：
  - 支持 `x-sheffield-signature` / `x-carrier-signature` / `x-webhook-signature` 的 HMAC-SHA256 签名校验。
  - 支持 `x-sheffield-webhook-timestamp` / `x-webhook-timestamp` 时间戳校验，默认 10 分钟有效窗口。
  - 支持 `x-sheffield-webhook-id` / `x-webhook-id` / `x-event-id` 或 body 事件编号的重复事件忽略，降低承运商重试导致重复轨迹写入的风险。
  - 兼容旧的 `x-sheffield-webhook-secret` / `x-webhook-secret` 密钥头，便于过渡接入。
- 新增取消面单能力：运营接口支持 `cancel_label`。
- 出库单新增承运商网关模式、承运商 provider、真实运单号、面单格式等字段。
- 新增 `/api/outbounds/[id]/label` 统一面单访问接口：
  - 客户只能访问自己的出库单面单。
  - 员工可访问全部出库单面单。
  - 真实承运商 `labelUrl` 会安全跳转到 PDF/ZPL。
  - 内部面单会直接返回可打印 HTML，不再只能通过员工打印页查看。
  - 客户面单导出、运营发货面板和仓库作业面单入口已改为走统一接口。

需要后续配置：

- `ROYAL_MAIL_API_KEY` / `DPD_API_KEY` / `EVRI_API_KEY` 或渠道 `credentialRef` 对应环境变量。
- `ROYAL_MAIL_LIVE_BASE_URL` / `DPD_LIVE_BASE_URL` / `EVRI_LIVE_BASE_URL`，或统一承运商中间层地址。
- `CARRIER_WEBHOOK_SECRET` 或各承运商独立 webhook secret。

- 承运商面单失败闭环增强：
  - 面单购买、渠道规则拦截、取消面单失败都会记录失败原因、尝试次数、最后尝试人和建议重试时间。
  - 运营发货面板会显示失败详情，可直接重试生成面单。
  - 真实承运商接口暂不可用时，运营可一键转为内部/人工面单，保留人工降级说明，仓库可继续打印作业。
  - 系统告警中心会展示面单失败原因、重试次数、建议重试时间和人工降级说明。

### 2. 平台订单 API 同步

- 新增 `platformGateway` 适配层。
- 平台连接 `api_sandbox` 可继续生成沙箱订单预检草稿。
- 平台连接 `api_live` 会调用平台订单同步网关，拉回订单后进入现有字段映射、异常校验和导入草稿。
- 出库单新增平台、平台订单号、店铺名和发货回传状态。
- 生成面单成功后，会尝试把追踪号回传给对应平台连接。
- 平台网关补强真实订单解析：
  - 支持 `line_items`、`lineItems`、`items`、`orderItems` 等多 SKU 行结构。
  - 支持 Shopify、TikTok Shop、eBay、Amazon 中间层常见的订单号、SKU、数量、发货日期字段别名。
  - 支持收件地址对象格式化，避免真实平台地址对象导入后变成 `[object Object]`。
  - 自动跳过已取消、作废或关闭的订单，减少误导入。

需要后续配置：

- `AMAZON_ORDERS_URL` / `TIKTOK_SHOP_ORDERS_URL` / `SHOPIFY_ORDERS_URL` / `EBAY_ORDERS_URL`。
- `AMAZON_FULFILLMENT_URL` 等平台发货回传地址。
- 平台连接备注中可写 `credentialRef=XXX_TOKEN`，由后端读取对应环境变量。

- 平台同步/导入预检草稿新增取消闭环：
  - 运营可在出库模块最近导入批次或批次详情页取消尚未确认的同步草稿。
  - 已取消批次不能再确认创建出库单，保留取消时间、取消人和取消原因。
  - 导入记录导出已补充取消字段，方便后续审计和问题复盘。

### 3. 生产级员工账号和权限

- 新增正式员工账号 store。
- 正式员工账号优先使用 Postgres 持久化，未配置数据库时回落本地文件，避免线上实例重启后账号丢失。
- 员工登录会优先校验正式员工账号，未命中再回退环境变量白名单。
- 新增 `/api/ops/staff-accounts`：
  - `GET` 查看正式员工账号。
  - `POST upsert` 邀请/启用/改角色/重置密码。
  - `POST disable` 禁用员工并记录原因。
- 登录接口增加频率限制，降低暴力尝试风险。

- 敏感操作二次确认已接入关键业务动作：
  - 库存调整审批命中二次确认规则时，审批人需要输入调整单号。
  - 月结账单锁定/解锁命中二次确认规则时，审批人需要输入 `客户编号-月份`。
  - 前端审批面板已补充二次确认输入框，错误提示由服务端统一返回，避免只在页面侧做弱校验。
- 正式员工角色变更新增审批闭环：
  - 已有员工修改角色时不会立即生效，会生成待审批记录并保留当前角色。
  - 权限页可查看正式员工账号、当前角色、登录状态、待审批目标角色，并可审批通过或驳回。
  - 角色变更提交、审批和禁用员工都会写入操作审计。
- 员工自助修改密码已补齐：
  - 新增 `/api/ops/staff-password`，正式员工登录后可校验当前密码并修改自己的密码。
  - 修改成功会写入操作审计，保留账号、角色和操作时间。
  - 运营后台顶部新增“修改密码”入口；环境变量白名单账号会明确提示需要在环境变量侧维护。

### 4. 文件和资料基础设施

- 文件记录新增存储方式、对象存储 URL、安全扫描状态、扫描说明和是否允许预览。
- 上传时执行基础安全扫描，阻止可执行脚本类风险文件。
- 上传安全扫描支持外部病毒扫描服务：
  - 配置 `VIRUS_SCAN_WEBHOOK_URL` 或 `CLAMAV_SCAN_URL` 后，基础扫描通过的文件会继续提交给外部扫描服务。
  - 扫描服务连接失败、返回感染/阻止状态或返回非 2xx 时，系统会阻止上传并展示原因。
  - 可选配置 `VIRUS_SCAN_TOKEN` 作为扫描服务鉴权令牌。
- 支持通用对象存储上传网关：`OBJECT_STORAGE_UPLOAD_URL` / `OBJECT_STORAGE_TOKEN`。
- 新增 `/api/documents/[id]/preview`，仅允许图片、PDF、文本类文件在线预览。
- 下载接口支持限时签名 token，已在运营资料中心和客户退货附件下载入口使用。
- 下载前会校验基础安全扫描状态，并增加 `no-store` 与 `nosniff` 响应头。
- 客户和员工上传大小统一改为 `MAX_UPLOAD_BYTES` 可配置，默认 20MB。

### 5. 财务实账自动生成

- 新增 `/api/ops/billing/auto-generate`。
- 可按客户/月自动生成：
  - 已发货出库基础处理费。
  - 出库 SKU 件数费。
  - 已生成面单的面单/贴标处理费。
  - 按运费基数计算的燃油附加费。
  - 按英国偏远邮编识别的偏远地区附加费。
  - 按重量或多包裹识别的超尺寸/多包裹附加费。
  - 退货质检费。
  - 退货重新上架费。
  - 退货销毁处理费。
  - 库存仓租草稿。
- 自动跳过已生成过的同类费用，减少重复入账风险。
- 月结单运营处理新增争议复核动作，客户提出争议后需要先复核恢复为已确认，再继续付款核销。

- 客户档案新增账期天数、信用额度和结算方式；费用生成时会按客户账期自动计算到期日，未配置时默认 7 天。
- 运营客户认证审核面板可维护账期与额度；账单复核表会直接标记逾期天数，方便财务优先处理超期账单。
- 付款核销补充驳回闭环：
  - 客户提交付款参考号后进入付款待复核。
  - 运营整月账单可登记收款，也可在凭证不合格时驳回付款。
  - 驳回原因会回显到客户月结单和单条费用中，客户可按原因重新提交付款。

### 6. 报表中心产品化

- 保存视图基础上新增定时报表配置。
- 新增 `/api/ops/reports/schedules`：
  - 查看定时报表配置。
  - 创建/更新日报、周报、月报收件人配置。
- 新增 `/api/ops/reports/schedules/run`：
  - 支持后台员工手动执行定时报表。
  - 支持 `REPORT_SCHEDULE_SECRET` 供 Cron 或外部调度触发。
  - 可根据日报、周报、月报判断是否到期。
  - 可通过 `REPORT_DELIVERY_WEBHOOK_URL` / `REPORT_DELIVERY_TOKEN` 投递到外部邮件、企微、飞书或自建发送服务。
  - 会回写最近执行时间、发送时间、投递状态和失败原因。
- 新增 `/api/ops/reports/staff-performance` 员工绩效报表：
  - 汇总员工扫码次数、异常次数、入库上架、出库签出、退货扫描、报表导出、账单操作和最近操作时间。
  - 支持日期、员工和模块筛选。
  - 已接入运营后台报表中心和保存视图，后续可复用到定时报表。
  - 增强出库作业指标：新增出库拣货、出库分拣、出库复核、出库称重、截单申请和截单回库统计，支持用 `module=outbound_review` 单独查看复核/截单相关员工产出。
- 保存视图与定时报表新增独立模块：
  - `outbound_review` 会导向 `/api/ops/reports/outbound-review`，用于复用出库复核差异、截单待审、待称重和数量缺口口径。
  - `customer_credit` 会导向 `/api/ops/reports/customer-credit`，用于复用客户信用风险、逾期账单和额度占用口径。
  - 运营后台保存视图下拉已补充“出库复核差异”和“客户信用风险”，避免只能手工点一次性导出。

### 7. 生产运维和安全

- 新增 `/api/ops/system/backup`，管理员可导出系统业务快照。
- 新增 `/api/ops/system/restore`，管理员可执行系统恢复：
  - 默认 `dryRun` 预检备份版本和核心数据结构。
  - 正式恢复必须传入确认短语 `RESTORE_WAREHOUSE_SYSTEM`。
  - 恢复范围包括核心仓储数据、扩展运营配置和资料元数据。
  - 恢复动作会写入审计日志。
  - 备份中已脱敏的对象存储链接不会被当成真实文件地址写回。
- 新增 `/api/ops/system/alerts` 系统告警接口，汇总上线体检、任务队列、平台同步、面单/回传、账单争议、库位容量和文件安全风险。
- 新增 `/api/ops/system/logs` 生产日志检索接口：
  - 聚合系统告警、批量任务和操作审计。
  - 支持关键词、级别、来源、日期和条数筛选。
  - 默认返回 JSON，`format=csv` 可导出中文生产日志。
  - 运营后台告警中心已增加“导出生产日志”入口。
- 新增 `/api/ops/system/health` 生产健康检查接口：
  - 仅员工登录后可访问，支持 JSON 和 `format=csv` 中文导出。
  - 汇总数据库连接、上线体检、外部集成配置、系统告警、任务队列、集成联调、文件安全、外部通知、员工账号治理和审计日志。
  - 输出总体状态、健康评分、关键业务指标和每个检查项的处理入口。
  - 运营后台总览新增“生产健康检查”面板，老板和运营可在发版前或每日开工前快速巡检。
- 运营后台概览新增“系统告警中心”，老板和员工可直接看到严重/提醒级别并跳转处理。
- 系统告警新增处理闭环：
  - 支持确认跟进、搁置 24 小时、关闭告警和重新打开。
  - 告警处理状态会持久化到 Postgres 或本地数据文件，刷新后不会丢失。
  - 每次处理会写入操作审计，保留处理人、备注、时间和搁置截止时间。
- 客户登录、员工登录增加内存级频率限制。
- 敏感运维接口增加频率限制：
  - 系统恢复 `/api/ops/system/restore`：10 分钟最多 5 次。
  - 定时报表执行 `/api/ops/reports/schedules/run`：10 分钟最多 20 次。
  - 生产日志查询 `/api/ops/system/logs`：1 分钟最多 60 次。
  - 员工自助修改密码 `/api/ops/staff-password`：10 分钟最多 8 次。
  - 生产集成联调探测 `/api/ops/integrations/probes`：10 分钟最多 12 次。
- 上线体检新增/强化：
  - 对象存储。
  - 正式员工账号治理。
  - 平台 API 同步。
  - 备份准备。
- 新增生产集成配置向导：
  - `/api/ops/integrations/readiness` 会按承运商、平台订单、文件存储、消息通知、报表投递和安全运维输出配置体检。
  - 运营后台总览可直接看到 Royal Mail/DPD/Evri、Amazon/TikTok/Shopify/eBay、对象存储、通知 webhook、报表 Cron 和安全密钥缺口。
  - 页面只展示环境变量名称和是否已配置，不展示任何密钥内容，方便后续在 Vercel 环境变量里逐项补齐。
- 生产集成联调探测新增闭环：
  - 新增 `/api/ops/integrations/probes`，管理员和运营可对承运商、平台订单、对象存储、外部通知、报表投递和病毒扫描执行 dry-run 探测。
  - 探测结果会持久化到 Postgres 或本地数据文件，运营后台总览会显示每个集成项最近一次探测状态、时间、执行人和失败原因。
  - 探测动作会写入操作审计，方便后续排查“是谁在什么时候验证了哪个外部接口”。
  - 最近一次探测失败或阻塞会进入系统告警中心，老板和运营不需要逐个展开配置项也能看到外部集成风险。
- 承运商面单生命周期报表新增闭环：
  - 新增 `/api/ops/reports/carrier-labels`，汇总出库单面单状态、承运商、服务、网关模式、追踪号、承运商运单 ID、失败原因、重试次数、下次重试时间、内部面单说明和平台回传状态。
  - 支持 `customerCode`、`status`、`mode`、`provider`、`keyword` 筛选，并支持 `format=json` 供看板、保存视图和定时报表复用。
  - 运营后台报表中心新增“导出承运商面单生命周期”，保存视图也可选择该模块，便于上线前检查 Royal Mail/DPD/Evri 面单购买、取消、fallback 和回传状态。

### 8. 消息中心、SLA 和任务队列

- 通知中心新增未读状态，支持单条已读、全部已读和关闭待办。
- 通知状态增加订阅配置，可按消息来源、严重程度和渠道配置站内信、邮件、短信、微信。
- 客户端和员工端通知接口返回未读数量和订阅配置。
- 外部通知投递新增可追踪台账：
  - 配置邮件、短信或微信渠道后，系统会为对应待办生成投递记录。
  - 未配置供应商 webhook 时标记为“待配置”，不会假装发送成功。
  - 新增 `/api/ops/notifications/deliveries` 查询和重试投递，运营后台消息配置区可查看最近投递状态。
- 入库、出库和工单通知增加 SLA 等级：
  - 入库超过 48 小时标记为 SLA 超时。
  - 出库超过 24 小时标记为 SLA 超时。
  - 工单超过处理口径自动升级为紧急提醒。
- 批量作业中心增加尝试次数、最大重试次数、错误原因、下次执行时间和完成时间。
- 新增 `/api/ops/jobs`，支持查询任务、查询可运行任务、标记处理中/完成/异常和重试异常任务。
- 运营后台批量作业卡片新增异常任务重试按钮。
- 出库波次与拣货效率增强：
  - 批量生成拣货波次在原有“按作业模式、承运商、渠道、合并波次”基础上，新增“按截单时间、按库区、按 SKU 热度”三种组波策略。
  - 按截单时间可把上午、下午、晚间订单分开处理；按库区可减少跨区走动；按 SKU 热度可把爆款/高频 SKU 和多 SKU 订单拆开作业。
  - 生成后仍沿用现有波次号、拣货单号、篮号/格口、打印拣货单和扫码拣货/复核/签出的闭环，不影响仓库端操作习惯。
  - 新增 `/api/ops/reports/pick-waves` 波次执行报表，按波次汇总订单数、客户数、SKU 数、应拣数量、拣货/配货/复核进度、已发货订单、异常数、承运商和最新扫描时间。
  - 运营后台出库批量处理面板新增“波次报表”下载入口，方便老板和仓库主管查看当天波次执行情况。

### 8.1 出库复核差异与截单异常报表

- 新增 `/api/ops/reports/outbound-review` 出库复核差异报表，按出库单汇总应拣数量、已拣数量、已分拣数量、已复核数量、拣货/分拣/复核缺口、未处理异常、严重异常、截单状态、重量、包裹数和下一步动作。
- 报表支持 `customerCode`、`status`、`result`、`keyword` 筛选，并支持 `format=json` 供保存视图、定时报表或后续看板复用。
- 运营后台报表中心新增“导出出库复核差异”入口，仓库主管可以快速定位需要复核、待称重、已截单或未开始的出库单。

### 8.2 出库截单审批闭环

- 新增 `outbound_intercept` 审批触发场景，审批规则中心可配置出库截单回库的审批角色、数量阈值、SLA、原因必填和附件必传。
- 仓库出库作业动作从单一“截单回库”拆为“申请截单”和“审批回库”：申请阶段只标记 `interceptStatus=requested`、记录原因和申请人，不释放库存；审批回库阶段才释放预占库存并写入截单回库日志。
- 截单回库接口会按审批规则校验员工角色、截单原因和审批附件，避免仓库端绕过运营审批直接回库。
- 审计日志新增“截单申请”动作；出库复核差异报表已区分“截单待审”和“已截单”，方便主管确认哪些单还在等待审批。

### 8.3 出库复核提醒与 SLA 看板

- 员工消息中心新增出库细分待办：截单待审、待称重签出、严重复核异常和拣货/分拣/复核数量缺口。
- 客户消息中心新增截单状态提示：客户可以看到出库单正在截单处理中或已经截单回库。
- 系统告警中心新增出库截单待审、待称重签出和复核数量缺口告警，老板和运营可在后台总览直接看到阻塞点。
- SLA 与异常报表面板新增“出库复核”指标和“导出出库复核”入口，优先处理队列会展示截单待审、待称重和复核缺口。

### 9. 深层 WMS 库位规则

- 新增统一库位放置校验：状态、容量、混放和特殊库位限制走同一套规则。
- 普通入库上架会在改状态前校验库位，失败时返回明确错误，不会误标为已上架。
- 采购到货整单上架接入库位容量和混放校验。
- 采购扫码上架接入逐件库位校验，扫码到停用/不存在/冻结位/残次品位会立即提示。
- 移库审批通过前再次校验目标库位，避免提交后库位状态或容量变化导致错误落库。
- 批次 / 效期 / 序列号管控增强：
  - 库存批次登记时会统一规范序列号大小写并拦截重复序列号。
  - 同一客户、同一 SKU 的未耗尽批次不能重复登记同一个序列号。
  - 预留、释放、消耗、冻结和启用批次时，会同步更新序列号状态。
  - 运营后台批次台账会显示可用、预留、已出库和冻结序列号数量，方便仓库和老板追踪高价值单件商品。

### 10. 客户自助异常确认

- 客户工作台“我的异常中心”新增物流/出库异常在线确认。
- 客户自助下载中心新增“资料包索引”：
  - 新增 `/api/downloads?kind=self-service-index`，客户可导出所有自助报表、模板文件、工单入口的中文索引。
  - 索引会标注每个下载项的用途、下载地址、当前客户是否已有相关数据和使用备注。
  - 客户工作台“可下载内容”增加“资料包索引”入口，方便客户内部转发给财务、仓库或运营同事。
- 客户自助下载中心新增“出库复核状态”：
  - 新增 `/api/downloads?kind=outbound-review`，客户可导出自己名下出库单的拣货、分拣、复核、截单、称重和异常处理状态。
  - CSV 表头保持中文，包含应拣数量、已拣数量、复核缺口、严重异常数、截单状态、包裹重量和客户可见下一步。
  - 资料包索引和客户工作台“可下载内容”已同步增加该入口，客户不用找运营单独导出。
- 支持客户直接确认改派、确认签收证明、提出赔付疑问或拒绝处理结果。
- 新增 `/api/outbounds/[id]/delivery-exceptions/[exceptionId]/decision`，按客户登录态限制只能处理自己的出库异常。
- 新增 `/api/outbounds/[id]/proof` 签收证明访问接口：
  - 客户只能访问自己的出库单签收证明。
  - 员工可访问全部出库单签收证明。
  - 已关联 POD 链接时安全跳转，未签收或未关联证明时返回明确原因。
  - 客户出库页和下载报表中的签收证明入口已改为走该接口。
- 出库异常记录新增客户确认结果、备注、确认时间和确认账号。
- 客户确认会写入出库操作日志，并同步追加到关联客户工单。
- 客户侧“物流异常与赔付”和“我的异常中心”导出补充客户确认信息。

### 11. 客户账期与信用额度风控

- 新增统一客户信用风险评估：汇总未结账单、逾期账单、逾期笔数、信用额度、额度剩余、结算方式和客户账号状态。
- 客户为预付结算且存在未结费用、存在逾期账单、超出信用额度或账号已暂停时，系统会将风险状态标记为 blocked。
- 客户出库 API 增加服务端拦截：允许 CSV 预览和保存草稿，但阻止直接创建出库单或批量确认创建，避免高风险订单进入仓库作业队列。
- 客户出库页面新增账期/信用状态卡片：展示未结费用、逾期金额、额度剩余和拦截原因，并在 blocked 状态下禁用提交出库按钮。
- 系统告警中心新增客户信用风险告警，运营和老板可以在后台直接看到因逾期、额度超限或账号暂停导致的出库拦截。
- 新增 `/api/ops/reports/customer-credit` 客户信用风险报表，支持按客户和风险状态筛选，输出客户状态、结算方式、账期、额度、未结金额、逾期金额、逾期笔数和风险原因；运营后台报表中心已增加下载入口。

## 仍需要真实外部条件的事项

- Royal Mail / DPD / Evri 正式 API 需要真实账号、测试环境、服务合同和密钥。
- Amazon / TikTok Shop / Shopify / eBay 正式 API 需要店铺授权和平台应用审核。
- 邮件、短信、微信通知需要选择供应商并配置发送密钥。
- 病毒扫描当前是基础规则，生产建议接 ClamAV 或云扫描服务。
- 对象存储当前走通用上传网关，生产可以接 Vercel Blob、S3 或自建对象存储中间层。
