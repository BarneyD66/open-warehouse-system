# 退货质检与售后工单闭环

## 目标

退货处理不只是后台改状态，还要让客户清楚看到退件是否到仓、质检结果是什么、后续是重新上架、维修翻新、报废还是转寄，并能通过工单继续沟通。

## 已落地能力

- 运营推进退货到“质检中、维修处理中、已报废、异常处理、已重新上架、已关闭”等状态时，系统会自动同步客户售后工单。
- 如果退货单还没有工单，会自动创建“退货售后”工单；如果已有工单，会追加客户可见的系统消息。
- 质检结果、处理方式、处理库位和运营备注会同步到客户工单。
- 退货重新上架、报废或关闭后，关联客户工单会同步结案。
- 运营后台退货表和客户退货页面都会显示关联工单号。
- 运营可在退货行内上传质检照片、破损图片、签收/入仓附件，客户侧可直接查看和下载。
- 客户下载“退货质检明细”时，CSV 会包含质检附件数量和附件名称，便于对账留档。
- 费用生成已按退货处理结果校验：未到仓/未质检不能生成质检费，未重新上架不能生成上架费，未报废不能生成销毁费。

## 使用路径

1. 客户在工作台提交退货预报。
2. 运营在后台更新退货状态和退货追踪。
3. 退件到仓后，运营填写质检结果、处理方式和库位。
4. 运营上传质检照片或相关附件，作为客户可见的处理凭证。
5. 系统自动创建或更新客户售后工单。
6. 客户在退货页面和工作台待办里查看质检结论、附件和工单进度，并按需回复。
7. 运营完成重新上架、报废或关闭后，工单同步关闭。
8. 财务按处理结果生成退货质检费、重新上架费或销毁费，系统会拦截不匹配的费用类型。

## 后续可增强

- 支持客户在工单里确认“同意报废 / 同意维修 / 要求转寄”后再推进状态。
- 支持退货 RMA 条码扫描到仓和拍照留档。
- 将退货附件按“到仓照片、外包装、商品细节、处理凭证”分类展示。
