# 46. 工单未读与超时提醒

## 已完成

- 客户待办中心接入工单消息：
  - 运营已回复时，客户会看到「运营已回复工单」。
  - 工单状态为「待客户补充」时，客户会看到「工单待您补充」。
  - 紧急工单或长时间未处理的工单会提升为紧急提醒。
- 运营待办中心接入工单消息：
  - 客户有新回复时显示「客户工单有新回复」。
  - 工单开启超过 24 小时未处理，或处理中超过 48 小时未推进，会显示「工单处理超时」。
  - 紧急工单直接进入高优先级提醒。
- 通知入口均保持中文文案，并跳转到对应客户工作台或运营后台处理区。

## 产品价值

- 工单消息不再埋在详情里，客户和运营都能在待办中心看到下一步动作。
- 对标马帮的「异常/客服/SLA」工作台习惯，避免客户回复后运营漏处理。
- 为后续做未读数、消息推送、SLA 报表和客服绩效统计打基础。
