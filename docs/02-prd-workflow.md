# 产品方案与工作流 PRD

## 产品目标

第一版目标是打通英国海外仓最核心的商用闭环：

客户入驻 -> SKU 建档 -> 入库预报 -> 收货上架 -> 库存可视化 -> 订单履约 -> 退货换标 -> FBA 中转 -> 异常处理 -> 费用账单。

第一版不追求完整 ERP，也不追求复杂仓内自动化，重点保证：

- 每一件货都有 SKU。
- 每一次入库有预报和收货记录。
- 每一份库存有来源和流水。
- 每一笔订单有状态和出库记录。
- 每一个异常有责任和处理结果。
- 每一项费用能追溯到业务单据。
- 每一个客户只能看到自己的数据。

## 核心业务流程

### 客户入驻

1. 客户注册账号。
2. 填写公司资料、联系人、平台店铺。
3. 上传营业执照、VAT/EORI、授权资料。
4. 提交审核。
5. 客服审核并生成客户编码。
6. 客户进入门户创建 SKU、入库、订单等业务单据。

控制点：

- KYC 未通过前限制正式入库和出库。
- 审核驳回必须填写原因。
- 合规资料变更需要审计留痕。

### SKU 建档

1. 客户创建 SKU。
2. 填写中文品名、英文品名、申报价值、HS Code、尺寸重量。
3. 标记带电、液体、粉末、敏感品、易碎品。
4. 上传商品图和标签。
5. 系统校验必填字段。
6. SKU 可用于入库、订单、退货、FBA。

控制点：

- SKU 编码在客户维度唯一。
- 资料不完整时不允许创建正式入库预报。
- 敏感品影响可用尾程渠道。

### 入库与上架

1. 客户创建入库预报。
2. 上传装箱单、发票、箱唛。
3. 仓库等待货物到仓。
4. 到仓后按箱号/SKU 收货。
5. 差异、破损、错货生成异常。
6. 正常货进入待上架。
7. 仓库分配库位并上架。
8. 上架完成后库存转为可售。

控制点：

- 实收和预报不一致必须形成差异记录。
- 未上架库存不可用于订单出库。
- 入库异常需要客户或后台处理后关闭。

### 订单履约

1. 客户创建或导入订单。
2. 系统校验地址、SKU 和库存。
3. 库存充足则锁定库存。
4. 订单进入待拣货。
5. 仓库按库位拣货。
6. 复核、打包、称重、选择渠道。
7. 生成或录入运单号。
8. 出库扫描。
9. 扣减库存并回传状态。

控制点：

- 订单提交后先锁库存，出库后再扣减实际库存。
- 缺货、地址异常、面单失败进入异常中心。
- 所有费用由订单出库事件触发。

### 退货换标

1. 客户创建退货预报或仓库收到未知退货。
2. 仓库登记退货追踪号和原订单。
3. 质检并拍照。
4. 判断可售、需换标、需换包、破损、销毁。
5. 客户确认处理方式。
6. 执行重上架、换标、销毁或转寄。
7. 生成退货处理费用。

### FBA 中转

1. 客户创建 FBA 中转单。
2. 填写 Amazon Shipment ID、目的 FBA 仓、FNSKU。
3. 上传箱标/商品标签。
4. 系统锁定库存。
5. 仓库拣货、贴标、换箱、打托。
6. 出库发往 Amazon FBA。
7. 生成 FBA Prep 和运输费用。
