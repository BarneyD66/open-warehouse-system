# 客户补充退货追踪号

## 目标

客户提交退货预报时，可能还没有买家退货追踪号。后续需要允许客户在工作台补充追踪号、预计到仓日期和备注，方便仓库到仓识别。

## 已落地能力

- 客户退货列表会在缺少买家退货追踪号时显示补充表单。
- 客户可填写退货追踪号、预计到仓日期和备注。
- 保存后退货单状态会从待处理推进到运输中。
- 客户待办中心会提醒“退货追踪号待补充”。
- 已重新上架、已报废或已关闭的退货单不能继续补充追踪号。
- 客户 RMA 标签已包含仓库寄回地址和 RMA 单号说明。

## 使用路径

1. 客户提交退货预报。
2. 客户拿到平台或买家的退货追踪号。
3. 回到退货页面，在对应 RMA 单下填写追踪号。
4. 仓库收到包裹后可通过 RMA 条码或退货追踪号定位退货单。

## 后续可增强

- 打印 RMA 标签前强提醒补充退货追踪号。
- 支持批量导入退货追踪号。
- 支持客户上传退货面单或平台退货截图。
