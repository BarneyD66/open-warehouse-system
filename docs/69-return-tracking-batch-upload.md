# 退货追踪号批量导入

## 目标

退货高峰时，客户或运营可能一次拿到多条买家退货追踪号。系统需要支持批量补充，避免逐单打开填写。

## 已落地能力

- 客户退货页面新增“批量补充退货追踪号”。
- 客户可下载中文 CSV 模板。
- 客户上传后只能更新自己账号下的退货单。
- 系统逐行校验退货单号和买家退货追踪号。
- 成功更新后，退货单状态会推进到“运输中”。
- 运营后台退货 / RMA 模块新增“批量导入退货追踪号”。
- 运营上传 CSV 后可跨客户更新退货追踪号，适合代客户整理表格。
- 导入结果会显示成功和跳过数量。
- 客户和运营都可以下载中文导入结果报告，用于修正跳过行。

## 模板字段

- 退货单号
- 买家退货追踪号
- 预计到仓日期
- 备注

## 后续可增强

- 导入前预检并展示逐行错误。
- 导入后生成可下载异常报告。
- 支持 Excel 文件和平台退货报表字段映射。
