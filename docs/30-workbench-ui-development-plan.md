# 专属仓储物流工作台 UI 与开发推进计划

## 目标

基于马帮系统学习结果，我们的工作台不照搬 ERP 大而全菜单，而是围绕英国自营仓业务做一套更轻、更直接的调度台：

- 客服先看询盘、报价、资料缺口和客户确认。
- 运营先看入库预报、预约、异常、费用和物流状态。
- 仓库先看到仓、验收、上架、拣货、包装、出库交接。
- 管理层先看待办、异常、履约 SLA、库存风险和费用差异。

## UI 方向

- 采用运营后台风格：高密度、表格化、队列化、少装饰。
- 首屏采用“指标 + 队列 + 异常表 + 处理卡片”的结构。
- 色彩不做单一蓝紫风格，使用白底、石墨色文字、青色主色、琥珀/红色异常、绿色完成。
- 图标统一使用 lucide-react，按钮和状态尽量配图标，减少大段解释性文案。
- 移动端以纵向队列为主，优先展示待办、异常和最近处理项。

## 第一阶段页面

1. 内部运营工作台 `/ops`
   - 总待办、高优先线索、入库待处理、物流异常、今日跟进。
   - 入库、库存、出库、物流四组任务队列。
   - 入库预报队列表。
   - 物流异常、库存观察、出库作业三个运营表。
   - 询盘报价和入库审核处理卡片。

2. 客户工作台 `/portal`
   - 保留客户任务流，但后续要同步优化为“待处理、货件、账单、异常”四个入口。

3. 移动端工作台
   - 第一屏只保留今日待办、异常、入库/物流关键状态。
   - 表格切换成横向可滚动列表或压缩卡片。

## 数据能力拆分

P0：
- 询盘、报价、入库预报、资料审核、状态流转。
- 入库队列和缺资料/缺追踪号规则。
- 运营备注、异常说明和客户时间线。

P1：
- SKU、库位、库存余额、库存流水、库龄分析。
- 出库订单、配货、包装验货、面单获取。
- 物流渠道、追踪节点、费用差异。

P2：
- 海外仓补货、调拨、盘点、库存同步。
- 物流规则引擎、渠道匹配、发货时效。
- 账单复核、客户确认、应收应付和成本利润。

## 设计与美术产出

- 后台主视觉不需要插画，重点是表格密度、状态色、图标一致性和信息层级。
- 官网、客户入口和登录页可以继续使用真实仓库/包裹/英国本地履约相关图片。
- 后续如果做移动端发布物料，可生成一组工作台截图风格的产品展示图，用于内部评审或客户演示。

## 当前已落地

- `/ops` 已从营销型后台页改为仓储物流调度台首屏。
- 询盘报价表单、入库状态表单已改为清晰中文。
- 工作台已预留物流、库存、出库模块的 UI 区域，后续可逐步替换成真实数据。
