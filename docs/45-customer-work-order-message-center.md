# 45. 客户工单消息中心

## 已完成

- 客户工单新增客户可见消息记录，支持客户和运营围绕同一个工单持续沟通。
- 客户提交新工单时，问题说明会自动成为第一条客户消息。
- 客户工作台「自助工单与售后沟通」支持在未关闭工单下继续回复。
- 运营后台「客户自助工单处理队列」支持回复客户，并自动把工单标记为「待客户补充」。
- 工单导出增加客户可见消息数和最后一条客户可见消息，方便运营追踪沟通状态。

## 产品价值

- 工单不再只是单次提交，而是形成可追踪的售后/客服对话。
- 物流异常、库存调整、账单争议和资料补充都可以留在系统内，减少微信或人工记录丢失。
- 后续可继续扩展为消息未读数、附件补充、自动通知和 SLA 超时提醒。
