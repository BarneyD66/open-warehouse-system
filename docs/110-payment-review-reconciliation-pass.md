# 110 - 付款复核与账单核销闭环

## 本轮目标

对标马帮类仓储系统的费用/账单日常运营，把客户提交付款凭证后的员工核销流程补成可操作、可审计、可导出的闭环。

## 已完成

- 单条账单新增明确的员工复核动作：
  - 确认到账：账单进入已付款，清理付款驳回信息。
  - 驳回付款：仅允许付款待复核账单驳回，回到已确认状态，并记录驳回原因。
  - 解除异议：争议账单恢复到已确认。
  - 重新打开：已付款或其他状态可重新回到已确认，便于财务纠错。
- 后台账单复核组件补充付款参考号输入和动作按钮，财务无需只靠下拉状态推进。
- `/api/ops/billing/[id]` 写入审计日志：
  - `billing_record_review` 账单状态复核
  - `billing_payment_review` 账单付款复核
  - `billing_invoice_review` 账单开票复核
- 审计日志新增 `billing` 业务类型，导出和前端筛选显示中文标签。
- 新增 `/api/ops/reports/payment-review` 付款复核清单：
  - 支持 CSV / JSON。
  - 字段包含账单、客户、金额、到期日、逾期天数、状态、付款参考、驳回原因、复核人、月结状态、风险等级和下一步处理。
  - 支持按客户、风险、状态、关键词筛选。
- 报表中心接入付款复核：
  - 快捷下载。
  - 保存视图。
  - 定时报表发送链接。
- 系统告警新增财务风险：
  - 付款凭证待复核，超过 48 小时升级为严重。
  - 付款凭证被驳回后待客户重新提交。
  - 账单逾期未处理，超过 30 天升级为严重。
