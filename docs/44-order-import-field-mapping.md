# 44. 订单导入字段映射增强

## 已完成

- 平台订单导入支持更多常见字段别名：
  - 客户编号、平台订单号、SKU 编码、数量。
  - 物流渠道、收件人、收件地址、要求发货日期、备注。
  - 兼容 `orderNo`、`orderNumber`、`order_id`、`seller_sku`、`qty`、`shippingMethod` 等平台常见字段。
- CSV 预检会在第 1 行提示缺少必填列，方便运营先修模板或维护平台字段映射。
- 新增字段映射说明导出：
  - `/api/ops/mabang-modules?template=order-mapping`
- 运营后台「平台订单导入和字段映射」增加「字段映射说明」下载按钮。

## 产品价值

- 订单导入更接近马帮的字段适配能力，不要求每个平台 CSV 都改成完全一样的表头。
- 异常提示前置到预检阶段，减少导入后才发现订单、SKU 或客户编号不匹配。
- 说明文件可以直接给运营或客户，降低首次导单沟通成本。
