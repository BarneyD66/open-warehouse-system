# 下载模板中文样例清理

本次针对中文模式下的下载模板和默认 CSV 样例做清理，保证客户和员工下载后看到的是中文优先内容。

## 已完成

- 客户侧出库订单导入模板示例行改为中文订单号和中文收件地址。
- 仓库侧出库订单导入模板示例行改为中文订单号和中文收件地址。
- 平台订单导入模板和沙箱同步预检示例改为中文地址和中文 SKU 提醒。
- 采购到货模板示例商品、追踪号、批次号改为中文样例。
- 追踪号上传模板中的地点改为中文城市名。
- 系统默认物流轨迹地点从 `Sheffield Warehouse` 改为“谢菲尔德仓库”。

## 保留项

Amazon、Shopify、Royal Mail、DPD、Evri 等平台/承运商专有名词保留英文，便于和真实业务单据匹配。
