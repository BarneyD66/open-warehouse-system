# 退货 RMA 扫码到仓与质检

## 目标

把客户退货预报、仓库实际到仓、运营质检、客户售后工单连成一条可追踪链路。员工扫一次码，老板和运营后台就能看到谁在什么时候扫了什么，客户侧也能同步看到处理进度。

## 已落地能力

- 仓库扫码台新增“退货/RMA”模式。
- 支持扫描退货单号、买家退货追踪号、原平台订单号定位退货单。
- 支持扫描 SKU 或库位记录质检过程。
- 扫码到仓会把退货状态推进到“已到仓”。
- 扫码质检会把退货状态推进到“质检中”，并写入质检记录。
- 每次扫码都会写入退货单扫码日志，包含动作、条码类型、SKU、库位、操作人和时间。
- 扫码结果会进入审计日志，老板可在运营后台查看退货相关操作记录。
- 扫码推进后会复用退货售后工单逻辑，把客户可见进度同步出去。

## 员工操作

1. 进入仓库工作台。
2. 在扫码作业台选择“退货/RMA”。
3. 选择“退货到仓”或“退货质检”。
4. 扫描 RMA 单号、买家退货追踪号或原平台订单号定位退货单。
5. 到仓后可扫描库位；质检时可继续扫描 SKU。
6. 扫码反馈区会显示退货单状态、库位、质检结果和最近扫码记录。

## 后续可增强

- 给退货单生成并打印 RMA 条码。
- 扫码时直接打开拍照上传入口。
- 质检完成后要求客户在工单里确认处理方式，再允许报废、维修或转寄。
