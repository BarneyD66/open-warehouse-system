# 库位利用率报表

## 本次新增

- 运营报表新增“库位利用率报表”，用于查看每个库位的容量、已占用数量、剩余容量、利用率和 SKU 数。
- 报表会自动标记“接近满仓、已超容量、未设置容量、库位停用、预留库位、混 SKU 风险、空库位、正常”等风险。
- 支持按仓库、区域、库区类型、状态、风险和关键词筛选。
- 保存视图支持选择“库位利用率”，后续可复用同一筛选口径导出。

## 对标马帮价值

- 仓库主管可以快速发现快满的库位、空库位、停用库位和混放风险。
- 运营可以把库位利用率作为仓库日报、盘点前检查和移库计划的依据。
- 报表全部使用中文字段，符合当前中文模式下对外和内部使用要求。
