# 77. 仓库扫码留痕报表

## 本轮目标

把仓库扫码作业从“页面可操作”补成“管理可追溯”，让老板和仓库主管能导出扫描记录。

## 已完成

- 新增 `/api/ops/reports/scans`。
- 覆盖出库拣货、配货、复核、签出、截单扫描。
- 覆盖退货/RMA到仓和质检扫描。
- 支持筛选参数：
  - `module`：`出库` 或 `退货/RMA`。
  - `action`：扫码动作，例如 `拣货`、`复核`、`退货质检`。
  - `customerCode`：客户编号。
  - `operator`：操作人。
  - `keyword`：关键词。
- 保存视图支持 `scans` 模块。
- 报表中心增加“导出扫码留痕”快捷入口。
- 仓库任务工作台顶部增加“导出扫码留痕”入口，现场主管可直接下载。

## 导出字段

模块、关联单号、客户编号、扫码动作、扫描内容、条码类型、SKU、数量、库位、重量KG、操作人、扫描时间、单据状态、单据说明。

## 价值

这让扫码作业不只是现场操作，还能形成可审计记录。后续排查错拣、漏扫、退货质检争议、员工效率和仓库 SLA 时，可以直接拿扫描流水对账。
