# 权限矩阵拦截与 SLA 异常报表

Date: 2026-05-31

## 对标马帮缺口

马帮类系统不仅有角色名称，还会按员工角色控制能看哪些模块、能做哪些敏感操作；同时运营首页需要把 SLA、异常率、费用差异和逾期账单集中展示，方便管理层优先处理风险。

## 本轮完成

- 新增 `staffPermissions` 权限 helper：
  - 支持 admin、ops、warehouse、finance 默认模块权限。
  - 支持读取运营后台保存的角色权限矩阵。
  - 支持模块访问校验和敏感操作校验。
- 运营后台左侧和移动端模块导航会按当前员工角色过滤。
- `/api/ops/mabang-modules` 新增模块权限拦截：
  - 订单导入和批量作业归属出库权限。
  - WMS 策略归属库存权限。
  - 物流渠道和承运商账单归属物流权限。
  - 费用规则归属账单权限。
  - 报表视图归属报表权限。
  - 权限矩阵配置仅允许有权限配置能力的角色操作。
- 运营总览新增“SLA 与异常报表”：
  - 入库 SLA。
  - 出库 SLA。
  - 物流异常。
  - 费用差异。
  - 逾期账单。
  - 优先处理队列。
- 新增中文 CSV 导出：`/api/ops/reports/sla`。
- SLA 导出支持按查询参数过滤：
  - `module`：`inbound`、`outbound`、`logistics`、`billing`、`sla`。
  - `customerCode`：客户编号。
  - `result`：正常、超时、异常、差异、逾期。
  - `status`：业务状态或追踪号。
  - `range`：`today`、`last_7_days`、`last_30_days`、`all`。
  - `keyword`：按单号、客户、状态、口径全文检索。
- 运营后台「高级筛选、保存视图与运营报表」新增常用导出：超时单、物流异常。
- 保存视图后，页面会展示最近视图，并可按同一筛选口径直接导出。

## 当前口径

| 项目 | 口径 |
| --- | --- |
| 入库 SLA | 提交后 48 小时内完成上架或关闭 |
| 出库 SLA | 创建后 24 小时内完成发货 |
| 物流异常 | 追踪异常、派送失败、改派或赔付未关闭 |
| 费用差异 | 实际运费与预估运费差异达到 £1 |
| 逾期账单 | 账单到期但未支付 |
