# 费用预估器交付记录

## 市场团队交接

市场团队继续把价格页需求交给产品经理：中文跨境卖家在发货前最关心“费用由哪些项目组成、我大概会花多少钱、为什么最终账单可能和预估不同”。竞品交付流程普遍会把服务选择、预计费用和实际费用分开表达，避免客户把预估当成最终报价。

参考来源：

- 万邑通入库/无箱单预报文档：入库流程中存在产品及费用预估，并强调预计费用为预估费用，最终以实际收费为准。
- 万邑通出库文档：支持查看费用明细。
- Mintsoft 3PL WMS：强调客户门户、3PL billing、按 storage、handling、picking、rework、shipping、returns 等活动计费。
- Karrio：可作为后续多承运商报价、面单和追踪抽象参考。

## 产品经理拆解

- 价格页不能只讲原则，需要提供可操作的估算入口。
- 估算字段要用客户能理解的业务语言：平台、服务、月订单量、入库箱数、库存体积、退货包裹、FBA 处理量。
- 结果要拆成费用来源：入库、仓储、出库、包材、退货、FBA Prep、增值服务。
- 必须明确免责声明：预估不代表最终报价，最终费用以仓库复核、服务项、包材和承运商账单为准。
- 移动端也要可填、可读、无横向滚动。
