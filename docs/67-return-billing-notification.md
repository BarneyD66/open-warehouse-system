# 退货费用待生成提醒

## 目标

退货质检、重新上架和报废会产生费用。系统需要提醒运营及时生成费用，避免退货已经处理完但账单漏掉。

## 已落地能力

- 通知中心会检查退货单是否已经进入可计费状态。
- 退货到仓、质检、维修、异常、重新上架、报废或关闭后，如果未生成质检费，会提醒运营。
- 退货重新上架后，如果未生成上架费，会提醒运营。
- 退货报废后，如果未生成销毁费，会提醒运营。
- 如果对应费用已经生成，不再重复提醒。
- 提醒会进入运营待办中心，来源归为账单。

## 使用路径

1. 仓库扫码到仓或运营推进退货质检。
2. 系统识别可生成退货质检费。
3. 运营待办中心出现“退货费用待生成”。
4. 运营进入账单生成模块，选择对应退货单和费用规则生成账单。
5. 已生成费用后提醒自动消失。

## 后续可增强

- 按客户合同自动设置是否免收退货质检费。
- 高价值销毁增加审批后再生成费用。
- 月结锁账时检查所有退货费用是否已生成。
