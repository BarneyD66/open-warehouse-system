# 账单月结与对账导出 MVP

## 本轮完成

- 客户 `/billing` 新增“月度对账”模块，按账单到期月份汇总账单数量、总额、待结算金额和已支付金额。
- 客户 `/billing` 每张账单新增“发票资料”上传入口，和已有付款凭证分开归档。
- 客户 `/billing` 每张账单新增“申请开票”动作，申请后账单进入“已申请开票”状态。
- 新增客户 CSV 导出接口：`/api/billing/export`，支持 `month` 和 `status` 查询参数。
- 运营 `/ops` 新增“月结对账导出”模块，按月份汇总全部客户账单，并支持导出最近月份或全部账单。
- 运营 `/ops` 新增开票状态维护，支持未申请开票、已申请开票、已开票、已作废。
- 运营 `/ops` 新增月结锁账动作，可按客户和月份锁定或解除锁定账单。
- 新增运营 CSV 导出接口：`/api/ops/billing/export`，支持 `month`、`customerCode` 和 `status` 查询参数。
- 新增运营月结锁账接口：`/api/ops/billing/statement`，支持 `lock` 和 `unlock`。
- CSV 字段包含账单号、客户编号、月份、月结状态、月结单号、开票状态、业务类型、关联单据、标题、状态、币种、金额、到期日、费用明细、客户说明、付款参考号、运营备注和创建时间。

## 验证记录

- `npm run lint` 通过。
- `npm run build` 通过，构建路由包含 `/api/billing/export` 和 `/api/ops/billing/export`。
- 本地客户账单页带客户会话访问可渲染“月度对账”“导出全部账单 CSV”“发票资料”。
- 本地运营后台带员工会话访问可渲染“月结对账导出”“费用规则生成”“账单复核”。
- 本地客户导出 `/api/billing/export?month=2026-06` 返回 `text/csv`，包含 `账单号` 与 `BILL-UK-24001`。
- 本地运营导出 `/api/ops/billing/export` 返回 `text/csv`，包含 `账单号` 与客户编号 `DEMO`。
- 本地客户账单页可渲染“申请开票”和开票状态。
- 本地运营后台可渲染“锁定月结”“解除锁定”“保存开票状态”。
- 本地客户账单 API 对 `request_invoice` 动作通过动作校验，未知账单返回 404。
- 本地运营月结锁账 API 对非法月份返回 400。
