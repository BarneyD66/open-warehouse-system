# 官网首页行动入口优化

## 背景

市场调研结论显示，中国跨境卖家首次访问海外仓网站时，最关心的不是抽象系统能力，而是“我现在该点哪里”。参考店小秘、马帮 ERP、4PX、谷仓海外仓、万邑通 Winit 的交付心智，首页需要把客户按阶段分流。

## 本轮产品决策

首页第一优先级改为“先估算月成本”。理由是多数新客户还在比价和判断是否适合英国仓，先看到成本区间更容易继续提交询盘。

首页保留五个可执行入口：

| 入口 | 适用客户 | 目标 |
| --- | --- | --- |
| 先估算月成本 | 还在比价、不了解费用结构的新客户 | 进入费用估算器 |
| 直接让客服报价 | 已知道基本需求、想人工确认报价的客户 | 提交询盘 |
| 我有货要入仓 | 已准备发货或正在安排头程的客户 | 创建入库预报 |
| 查进度和待办 | 已提交询盘、ASN 或追踪号的客户 | 查询当前状态 |
| 进入客户工作台 | 已合作客户 | 查看库存、订单、账单和异常 |

## 页面调整

- 首页 hero CTA 改为：先估算月成本、直接让客服报价、我有货要入仓、查进度。
- “下一步怎么做”区域改为五个客户入口，并使用独立 CTA 文案。
- 五个入口增加阶段标签：还在比价、想确认能不能做、准备发货、已经提交过、老客户日常运营。
- 价格页把费用估算器前置到费用结构之前。
- 询价成功页增加“客服报价队列”说明、下一步说明和“复制询盘编号”按钮。

## 验收标准

- 首页首屏能看到“先估算月成本”。
- 首页下一步区域能看到五个客户动作入口。
- 首页下一步区域能看到“我现在处在哪一步？”和客户阶段标签。
- 价格页进入后优先看到费用估算器。
- 询价提交成功后能看到询盘编号、下一步说明和复制编号按钮。
- 移动端 390px 无横向滚动。
