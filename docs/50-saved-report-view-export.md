# 保存视图导出与审计

## 本次补强

- 运营后台保存的报表视图现在通过 `/api/ops/reports/views/[id]` 统一导出。
- 服务端会先校验员工登录态与报表权限，再读取保存视图中的筛选条件。
- 导出前会写入审计日志，记录导出人、视图名称、报表模块、筛选条件和指标口径。
- 库存类视图继续导向库存报表；订单、物流、账单、利润和 SLA 类视图继续导向 SLA/异常报表。
- 直接点击库存、库龄、进销存、库存对账、SLA、物流异常等报表导出时，也会写入 `report_export` 审计日志。
- 库存报表和 SLA/异常报表的 CSV 文件名、表头、结果和处理建议已统一为中文，避免中文模式下下载内容出现英文或乱码。

## 对标价值

马帮类系统的运营后台强调“查得快、口径可复用、操作可追溯”。保存视图导出补齐后，运营可以把低库存、物流异常、账单逾期、客户专属筛选等常用口径固定下来，老板和管理员也能在审计日志里看到是谁导出了哪一套数据。
