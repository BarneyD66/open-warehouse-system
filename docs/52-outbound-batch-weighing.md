# 出库批量称重

## 本次补强

- 运营后台出库模块新增“批量称重与运费重算”。
- 可下载 `出库批量称重模板.csv`，填写出库单号、包裹重量 KG、包裹数和备注。
- 导入后系统会批量更新出库单的包裹重量、包裹数和预估运费。
- 运费会沿用当前物流渠道配置，包含偏远、燃油、超尺寸和黑名单规则。
- 命中渠道限制时，出库单会被标记为面单失败，并在运费备注中保留原因。
- 每次批量称重导入都会写入 `outbound_batch_weighing` 审计日志。

## CSV 模板

```csv
出库单号,包裹重量KG,包裹数,备注
OUT-202606-0001,1.25,1,打包台称重
```

## 对标价值

马帮类仓库作业里，称重不是单票手工记录，而是打包台日常批量动作。批量称重接入后，仓库可以先完成打包称重，再由系统按物流规则统一重算运费，运营和财务也能在审计日志里追溯谁导入了称重数据。
