# 深层 WMS 库存批次风险报表

## 本轮目标

批次、效期、序列号、冻结库存和 FEFO/FIFO 规则已经有底层能力，但运营和老板还需要一个可导出、可保存视图、可定时发送的批次风险报表，用来日常发现临期、过期、冻结和序列号异常。

## 已完成

- 新增运营报表 `/api/ops/reports/inventory-lots`。
- 报表字段覆盖批次 ID、客户编号、SKU、仓库、库位、批次号、效期、距到期天数、批次状态、可用/预留数量、序列号状态、风险等级、风险原因和 FEFO 建议。
- 风险识别包含批次冻结、已过期、30 天内临期、仅剩预留库存、冻结序列号和批次耗尽。
- 支持 `customerCode`、`skuCode`、`status`、`risk`、`keyword` 筛选，并支持 `format=json` 给后续看板复用。
- 已接入保存视图 `/api/ops/reports/views/[id]` 和定时报表 `/api/ops/reports/schedules/run`。
- 运营后台报表快捷区新增“导出库存批次风险”入口。

## 产品价值

这让 WMS 从“登记批次信息”进一步变成“主动管理批次风险”：仓库能按 FEFO 优先出临期批次，运营能发现冻结/过期风险，老板能定期看到批次和序列号管控是否真正落地。
