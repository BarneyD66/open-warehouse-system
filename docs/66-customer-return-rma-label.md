# 客户侧 RMA 标签打印

## 目标

客户发起退货预报后，可以自行打印 RMA 标签并随包裹寄回。仓库收到退货后直接扫码识别，减少人工查找原订单或追踪号。

## 已落地能力

- 客户退货列表新增“打印 RMA 标签”入口。
- 客户只能访问自己账号下的退货单标签。
- 标签包含 Code 128 条码、客户编号、平台、原订单号、买家退货追踪号、预计到仓和 SKU 明细。
- 标签提示客户打印后贴在外箱或放入包裹。
- 仓库收到后可在扫码台选择退货/RMA 模式扫描 RMA 条码。

## 使用路径

1. 客户登录工作台并进入退货页面。
2. 提交或查看退货预报。
3. 点击“打印 RMA 标签”。
4. 打印标签并随退货包裹寄回。
5. 仓库到仓后扫码推进状态和质检。

## 后续可增强

- 客户打印前强制补充买家退货追踪号。
- 标签增加仓库收货地址和寄回注意事项。
- 支持批量下载客户自己的 RMA 标签 PDF。
