# 演示登录入口

## 产品判断

首页需要保留登录入口。原因是客户会自然区分两类状态：

- 新客户：看服务、估费用、提交询盘、创建入库预报。
- 老客户：登录客户门户，看库存、入库、报价、异常和账单。

因此本轮新增 `/login`，作为客户门户的演示入口。

## 当前实现

- 新增 `/login` 页面。
- 顶部导航新增“客户登录”。
- 测试账号：`test`

- 登录成功后跳转 `/portal?demo=1`。
- 客户门户展示“测试账号已登录”提示，说明当前为演示门户。

## 技术边界

当前只是前端演示登录，用于网站原型体验：

- 登录校验在前端完成。
- 登录状态写入 `localStorage`。
- 不做真实权限和客户数据隔离。

正式 MVP 需要补充：

- 数据库用户表。
- 密码哈希。
- 会话 Cookie。
- 客户数据隔离。
- 登录日志。
- 角色权限。
- 密码重置。
