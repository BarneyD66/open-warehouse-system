# 演示登录入口

## 产品判断

首页需要保留登录入口。原因是客户会自然区分两类状态：

- 新客户：看服务、估费用、提交询盘、创建入库预报。
- 老客户：登录客户门户，看库存、入库、报价、异常和账单。

因此本轮新增 `/login`，作为客户门户的演示入口。

## 当前实现

- `/login` 页面已升级为客户登录和自注册入口。
- `/workspace` 也提供客户注册、登录和忘记密码重置入口。
- 新客户注册后会自动生成客户编号并进入 `/portal`。
- 老客户可以用手机号或邮箱登录。
- 员工不从 `/login` 进入，员工使用 `/ops-login`。

## 技术边界

当前客户登录已经不是早期前端原型登录：

- 客户密码会哈希后存储。
- 客户会话使用签名 Cookie。
- 客户数据按客户身份隔离。
- 客户账号支持资料维护、修改密码和重置密码。

本地开发仍可使用 fake/demo 数据演示业务流程，但不再使用固定的 `test / test` 客户账号。

## 员工演示账号

员工登录入口是 `/ops-login`。本地开发默认白名单账号和生产配置要求见 `docs/STAFF_AUTH.md`。

生产环境必须配置 `SESSION_SECRET` 和 `STAFF_WHITELIST_JSON`，并保持 `ALLOW_DEMO_LOGIN`、`ALLOW_DEMO_STAFF_LOGIN` 关闭。
