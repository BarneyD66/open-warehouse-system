# 采购补货到货签收

本轮补齐马帮类系统里常见的“采购/补货到仓签收”链路，让运营能把供应商发来的补货计划和仓库签收、上架、库存流水串起来。

## 已落地

- 新增采购到货单模型：供应商、客户编号、仓库、预计到仓、追踪号、SKU 明细、预计数量、已签收数量、已上架数量。
- 新增状态流转：在途、部分签收、已签收、已上架、异常、取消。
- 运营后台入库模块新增“采购补货到货签收”面板。
- 支持手工创建采购到货单。
- 支持整单签收：签收数量进入待上架库存。
- 支持确认上架：待上架数量转为可售库存。
- 签收和上架都会写入库存流水，并记录运营审计。
- 新增中文 CSV 模板：`采购到货签收模板.csv`。

## 后续增强

- 批量导入采购到货单。
- PDA 扫追踪号、箱唛、SKU 条码后自动定位到采购到货单。
- 签收差异拍照、质检、少货/多货/破损审批。
- 按供应商、客户、SKU、到仓日期筛选采购到货队列。
