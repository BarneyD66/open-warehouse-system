## 合作询盘表单

字段包括：

- 公司/店铺名称
- 联系人
- 手机/微信
- 邮箱
- 销售平台
- 预计月单量
- 主要服务需求
- 货物所在地
- 需求描述

已实现：

- 必填校验
- 邮箱格式校验
- 提交中状态
- 成功编号
- 成功后的继续提交和创建入库预报入口

## 入库预报表单

字段包括：

- 客户/店铺名称
- 联系人
- 手机/微信
- 平台
- 预计到仓日期
- 运输方式
- 承运商/追踪号
- 箱数/托数
- SKU 数量
- 主要品名/SKU
- 需要的服务
- 特殊属性
- 附件上传入口
- 信息确认勾选

已实现：

- 必填校验
- 日期不能早于当天
- 箱数/SKU 数量必须大于 0
- 信息确认勾选校验
- 提交中状态
- 成功生成 ASN 编号
- 成功后的继续提交和查看仓库位置入口
