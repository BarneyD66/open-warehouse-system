# 42. 物流配置接入匹配与库存报表

## 已完成

- 物流一键匹配不再只依赖内置静态规则，会读取运营后台维护的物流渠道配置。
- 已启用或沙盒状态的 Royal Mail、DPD、Evri、人工渠道、FBA/平台仓规则会优先参与推荐。
- 运营角色访问物流匹配接口时，会先校验是否有物流模块权限。
- 新增运营报表导出接口：
  - `/api/ops/reports/inventory?kind=aging`：库龄分析报表。
  - `/api/ops/reports/inventory?kind=turnover`：进销存报表。
  - `/api/ops/reports/inventory?kind=reconcile`：海外仓库存对账报表。
- 库存报表导出支持筛选参数：
  - `customerCode`：客户编号。
  - `warehouse` 或 `warehouseCode`：仓库编号。
  - `location` 或 `locationCode`：库位。
  - `sku` 或 `skuCode`：SKU 编码。
  - `risk`：低于预警、库龄偏高、存在冻结、存在残次品。
  - `keyword`：按客户、仓库、库位、SKU 和风险全文检索。
- 报表表头、文件名和可见字段均为中文，方便直接发给运营、仓库和财务核对。
- 运营后台「高级筛选、保存视图与运营报表」区域新增库龄、进销存、库存对账、低库存导出按钮。
- 保存视图支持按视图条件一键导出；同名、同模块、同角色视图再次保存会更新原视图，避免重复堆积。

## 产品价值

- 物流配置和实际订单匹配开始形成闭环：运营配置的渠道不再只是展示数据，而是会影响发货推荐。
- 库存从单纯列表升级为可导出的经营报表，方便检查库龄风险、流水缺口、库存异常和月度进销存。
- 对标马帮的报表中心能力继续补齐，为后续客户侧自助下载和财务月结归档打基础。
